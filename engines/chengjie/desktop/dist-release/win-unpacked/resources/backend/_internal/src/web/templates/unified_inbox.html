关于平台连接
各平台支持多账号接入，点击平台右侧「＋ 扫码新增」即可添加。各平台接入方式不同，见下：
• Telegram：扫码 / API 授权直连（最稳）
• LINE：真机接入（需 adb 设备 + 手机 LINE）；协议扫码为可选项
• WhatsApp：扫码登录（需本机连接服务在运行）
• Messenger：在服务器端弹出的浏览器窗口内登录
账号断线后可在对应卡片点「重连」自助恢复；Messenger 断线用卡片上的「重新登录」。
