智聊 ChatX — 安装提示 / Install notice
========================================

【中文】
1) 若 Windows 弹出蓝底「已保护你的电脑」（SmartScreen）：
   点击「更多信息」→「仍要运行」。这是未建立签名信誉时的例行提醒，不是病毒报警。
   请只从 https://bd2026.cc 下载，并用下载页公布的 SHA-256 核对安装包。

2) 若出现红底「已被应用程序控制策略阻止」（Smart App Control 强制模式）：
   安装程序无法提供「跳过」——这是系统策略硬拦截。请换一台未强制开启 SAC 的电脑，
   或联系客服索取已代码签名的安装包。

3) 安装完成后无需填写任何云 API Key。翻译与智能回复经官网安全通道自动可用；
   Key 只保存在服务端，不会出现在你的电脑上。

【English】
1) Blue SmartScreen "Windows protected your PC":
   Click More info → Run anyway. Routine reputation warning for unsigned/new builds.
   Download only from https://bd2026.cc and verify SHA-256 on the download page.

2) Red "Application Control policy has blocked this file" (Smart App Control enforced):
   Cannot be skipped in the installer. Use a PC without SAC enforced, or ask for a signed build.

3) No cloud API key to enter after install. AI runs via our secure gateway; the vendor key
   never leaves the server.
