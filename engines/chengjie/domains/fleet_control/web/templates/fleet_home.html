出站直连

受控电脑只往外连主控（HTTPS 长轮询），家庭宽带 / 4G / 机房 NAT 后都能用，断线自动重连。

只传指标，不传聊天

心跳只带版本、实例、账号数、健康状态、看板汇总数字；聊天原文永远留在本机。

一机一钥

注册码一次性、限时；注册后签发本机专属 node_key，主控随时可吊销或换钥。

任务幂等

ping / 拉看板 / 账号健康 / 集中扫码 / STOP 触达 / 重启实例；每条带 TTL，重复送达不重复执行。

三步接入

1
在主控后台生成注册码
登录 /fleet/console → 「生成注册码」（8 位数字，默认 60 分钟内有效，只能用一次）。
2
在受控电脑安装
以管理员打开 PowerShell，一条命令完成下载校验、登记本机智聊实例、注册、开机自启（计划任务 SYSTEM）： 
powershell -ExecutionPolicy Bypass -File Install-ChatXAgent.ps1 -Controller {{ public_url }} -Code ＜注册码＞
已有源码环境的机器也可： 
python -m src.fleet.agent enroll --controller {{ public_url }} --code ＜注册码＞
python -m src.fleet.agent install-service
3
回到主控后台
几秒内节点变为「在线」，即可查看实例 / 账号状态并下发任务。重装系统后用新注册码重新接入，节点身份不变。

安全与边界

主控不会反向连接、不会远程桌面、不会读取聊天记录；能做的只有契约里列出的任务种类。 每台电脑的 node_key 只存在本机 %ProgramData%\ChatX\fleet，主控只保存其哈希。 所有请求经 HTTPS；注册码过期或用过即失效。完整契约见 docs/FLEET_CONTROL_CONTRACT.md。
