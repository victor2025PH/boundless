出站直连

受控电脑只往外连主控（HTTPS 长轮询），家庭宽带 / 4G / 机房 NAT 后都能用，断线自动重连。

只传指标，不传聊天

心跳只带版本、实例、账号数、健康状态、看板汇总数字；聊天原文永远留在本机。

先批准，再发令

公开安装包不会自动拿到控制权。管理员在后台点批准之后，这台电脑才有自己的 node_key，才能领任务。

任务幂等

ping / 拉看板 / 账号健康 / 集中扫码 / STOP 触达 / 重启实例；每条带 TTL，重复送达不重复执行。

三步接入

1
下载安装包，双击
弹出权限确认时点「是」。安装程序会自己找到本机的智聊和幻颜；一台都没有也能装上，只上报这台电脑在线。
2
在主控后台点批准
打开 主控后台，这台电脑在「待批准」里，能看到主机名、IP 和探测到的实例。点批准之后它才上线。
3
看一眼开始菜单
「智控节点状态」能确认本机已经接入。整间机房要一次装很多台时，管理员先在后台生成「机房安装包」，每台电脑打开那个链接再双击 Install.cmd，会直接进指定分组，不用逐台批准。

安全与边界

主控不会反向连接、不会远程桌面、不会读取聊天记录；能做的只有契约里列出的任务种类。 没被批准的电脑没有 node_key，领不了任务。node_key 只存在本机 %ProgramData%\ChatX\fleet，主控只保存其哈希。 机房安装链接是密钥，不出现在这个公开下载页上。所有请求经 HTTPS。完整契约见 docs/FLEET_CONTROL_CONTRACT.md。
