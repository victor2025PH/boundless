出站直连

受控电脑只往外连主控（HTTPS 长轮询），家庭宽带 / 4G / 机房 NAT 后都能用，断线自动重连。

只传指标，不传聊天

心跳只带版本、实例、账号数、健康状态、看板汇总数字；聊天原文永远留在本机。

先批准，再发令

公开安装包不会自动拿到控制权。管理员在后台点批准之后，这台电脑才有自己的 node_key，才能领任务。

任务幂等

ping / 拉看板 / 账号健康 / 集中扫码 / STOP 触达 / 重启实例；每条带 TTL，重复送达不重复执行。

三步接入

1
下载安装器，双击
弹出权限确认时点「是」；被 SmartScreen 拦下时点「更多信息」→「仍要运行」。不需要输入任何码。安装程序会自己找到本机的智聊和幻颜；一台都没有也能装上，只上报这台电脑在线。
2
把配对码发给管理员，在主控后台点批准
安装完成页会显示一个配对码。管理员打开 主控后台，这台电脑在「待批准」里，能看到同一个配对码、主机名、IP 和探测到的实例。核对后点批准，它才上线。
3
打开「智拓群控节点」
桌面或开始菜单的「智拓群控节点」（旧版叫「舰队节点」）是这台电脑的本机页，能看到待批准、在线、离线或已拒绝。批准和查看其它电脑仍去主控后台。整间机房要一次装很多台时，管理员先在后台生成「机房安装包」，每台电脑打开那个链接再双击 Install.cmd，会直接进指定分组，不用逐台批准。

一键重装 / 修复

A
保留身份重装（最常用）
直接再运行一次上面的安装器（覆盖安装）。安装程序会先停掉本机节点，再换新文件；这台电脑保留原来的节点身份，不用重新批准。{% if download.setup_url %}下载 v{{ download.version }}{% endif %}
B
彻底重装（换身份）
以管理员身份运行 "%ProgramFiles%\ChatX Agent\unins000.exe" /VERYSILENT /REMOVESTATE=1，再运行安装器。电脑会以新身份进「待批准」，照第 2 步把新的配对码发给管理员；如果管理员给了本机房的「机房安装包」，双击其中的 Install.cmd 会直接进分组，不用逐台批准。机房安装包由管理员发放，不在本页公开。
C
装完核对
打开桌面「智拓群控节点」看到「在线」；管理员在主控后台看到这台电脑，版本号与上面一致。

安全与边界

主控不会反向连接、不会远程桌面、不会读取聊天记录；能做的只有契约里列出的任务种类。 没被批准的电脑没有 node_key，领不了任务。node_key 只存在本机 %ProgramData%\ChatX\fleet，主控只保存其哈希。 机房安装链接是密钥，不出现在这个公开下载页上。所有请求经 HTTPS。完整的任务契约可向管理员索取。
