# 模板快照恢复与编码损毁防线（2026-08-22 事故沉淀）

> 事故：14:22 某编辑会话把 `unified_inbox.html` 以错误编码链保存（UTF-8 被按
> GB18030/CP936 读入再存出）——全文中文乱码、体积 +30%，乱码恰好吃掉第 2 行
> Jinja 字符串闭合引号 → `/workspace` 500，**全部坐席宕机 ~28 分钟**。同一会话
> 还污染了桌面镜像 `desktop/renderer/shared/copilot/app.html`（若未发现会随下次
> 打包出货）。模板热更新＝保存即生产，此类损毁没有部署前拦截点。

## 一、损毁识别（30 秒判定）

1. 页面 500 + `boot_*.err.log` 尾部 `TemplateSyntaxError`（报错行常是**受害行**，
   真凶可能是前面被吃掉的引号）；
2. 文件体积异常膨胀 ~+30%（中文 3 字节 → 乱码 4.5 字节）；
3. `python -m pytest tests/test_encoding_integrity.py`——常驻门禁，直接点名损毁文件；
4. 乱码肉眼特征：`鐨勶紝銆屾` 类生僻字连片 + 零星 `?`（`?` 是有损转码的永久空洞）。

## 二、恢复 SOP（按优先级选 donor）

| 优先级 | donor | 新鲜度 | 位置 |
|---|---|---|---|
| 1 | 打包用后端快照 | 最近一次 `build:backend`（发版日=当天凌晨） | `desktop/build/backend-dist/_internal/src/web/templates/` |
| 2 | 解包安装目录 | 同上 | `desktop/dist/win-unpacked/resources/backend/_internal/src/web/templates/` |
| 3 | git HEAD | **常落后数天**（共享树 wip 快照节奏），先 `git log -1 --format=%ci -- <file>` 看日期再用 | `git show HEAD:<path>` |
| 4 | 乱码逆变换 | 仅作**内容参考**，绝不直接上线 | 见下方逆变换 |

步骤：

1. **保全现场**（先于一切）：把损毁件拷到 `D:\chengjie-instances\.ops\<名>.CORRUPT_<时间>.html`；
2. **二进制拷贝恢复**：`cmd /c copy /Y <donor> <live>`（禁用任何带编码解释的管道）；
3. **重放 donor 之后的增量**：查意向板 `agent_probe.ps1` 里 donor 时间点之后声明
   HOT-LIVE 过该文件的各条线，逐条点名让 owner 重放（不要替改）；自己的增量自己重放；
4. **验证**：授权态打开页面（**别用未登录 urllib——会被重定向到 login 假 200**）+
   `tests/test_encoding_integrity.py` + 相关门禁 + bump `ui-build.txt`；
5. **通报**：意向板挂事故结案（含 donor 时间点、丢失清单、保全件路径），并警告
   肇事编辑器「缓冲区还是损毁字节，保存前先从磁盘重载」。

逆变换（找回损毁件里的独有内容作参考）：

```python
open(out, "w", encoding="utf-8").write(
    open(corrupt, encoding="utf-8").read().encode("gb18030").decode("utf-8", "replace"))
# U+FFFD = 永久空洞；带洞区块禁止直接回贴（本次实测 4 万行 1.4 万洞）
```

## 三、编码纪律（防再犯）

1. **文件拷贝一律二进制语义**：`copy /Y` / `shutil.copy` / `robocopy`。
   ⛔ PS5.1 `Get-Content | Set-Content` 不带 `-Encoding` ＝ 按 ANSI(GBK) 读 UTF-8，
   就是本次事故向量；PS5.1 `*>>` 重定向混写 UTF-16 是姊妹坑（夜间日志已踩过）。
2. **双树镜像**（`shared/copilot` → `desktop/renderer/shared/copilot`）是人肉拷贝
   同步，必须用二进制拷贝；字节一致由 `tests/test_copilot_shared_sync.py` 钉住。
3. **常驻门禁** `tests/test_encoding_integrity.py`：模板/静态 JS/i18n packs/copilot
   双树全扫（UTF-8 严格解码 + 零 U+FFFD + 乱码指纹阈值）；SVG 等工具导出资产刻意
   不在防护面。良性命中登记 `_ACCEPTED` 附原因。
4. 损毁可能**多点着弹**（本次：主模板 + 桌面镜像 + 恢复窗口期又被补了一枪）——
   恢复后必须全站重扫，别只验被报障的那个文件。
