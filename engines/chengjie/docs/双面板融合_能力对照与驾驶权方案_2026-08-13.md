## 1. 双链是什么

同一个账号有两个操作面（两条链），共享同一个后端大脑（AI / 翻译 / 审计 / 风控 / 去重）：

| | **自研链（workspace，工作台）** | **官方链（native，原生页）** |
|---|---|---|
| 载体 | 统一收件箱 + 服务器端协议 worker（TG pyrogram / WA Baileys / Messenger Playwright sidecar） | ChatX 桌面壳内嵌官方网页标签（web.telegram.org/k、web.whatsapp.com、messenger.com）+ 注入层 |
| 登录态 | 服务器持有（协议 session / 边车浏览器 profile） | 坐席机 webview 各自登录（TG 多端原生共存；WA 多设备伴侣位；Messenger 独立会话） |
| 强项 | **全自动产能**（拟稿→自动投递）、翻译、记忆/人设、审计、跨账号聚合 | 官方全功能：**通话、转发、置顶、举报**、表情回应、消息即时性；注入层给翻译/AI 草稿辅助 |
| 差异要点 | tg/wa 走协议栈（能力最全）；msgr 走网页 sidecar | tg/wa 注入是**完整定制档**（可回流消息、有受控出站链）；msgr/ig/x/zalo 是 assistOnly 工厂档（禁伪全自动） |

**融合 = 四件套**：能力注册表（哪边能干什么，缺的去哪，永不静默消失）＋ 驾驶权互斥锁（同一账号同一时刻只有一面在自动发送，防双发）＋ 跨面深链（工作台一键跳到原生页同一会话）＋ 让位强制执行点（AutosendWorker L2 + protocol_autoreply 协议直发链）。

| 已读回执 | ● | ● | `mark_read`（pyrogram read_chat_history）；官方原生 |

| 举报 | ↗ | ● | 同上 |
| 语音/视频通话 | ↗ | ● | WebRTC 实时媒体，协议栈技术上不做；官方 web 支持 1:1 通话 |

## 5. 防双发：驾驶权互斥锁（方案核心）

- 每个「平台:账号」有唯一**自动化持有者**：`workspace`（默认）或 `native`；落盘
  `<实例数据根>/config/surface_pilot.json`（mtime 失效缓存 + 50 条审计历史）。
- **强制执行点（两条自动链都闸）**：
  1. AutosendWorker：投递前查锁，owner=native → 取消 L2 草稿（`decided_by=pilot_native`，
     计数 `total_skipped_pilot`），人工通过不受影响；
  2. protocol_autoreply 协议直发链：**生成前**早退（原因码 `pilot_native`，不打「需人工」、
     不进审计）——ChatX 独立包默认档（`deliver=false`）下这条才是自动发送主力，
     只闸 worker 锁不闭合（本批修复，Messenger 一并受益）。
- 全程 fail-open：锁文件坏/判定异常一律放行，锁故障绝不闸死自动回复。
- 为什么 tg/wa 比 msgr 更需要：msgr 原生页被禁全自动（单向锁就够）；**tg/wa 原生页
  自带受控出站链（两面都能发）**，不锁＝客户收到两份回复。
- 已知边界（P2 排期）：原生页受控出站**反向让位**（owner=workspace 时壳侧注入链让位）
  尚未接线——当前靠「原生页 assist 档默认人审」兜住；主动触达链（proactive/care）未接锁，
  坐席部署默认关无实弹风险。

## 6. 跨面深链（工作台 → 原生页同一会话）

| 平台 | URL 形态 | 失败形态（为何安全） |
|---|---|---|
| Messenger | `messenger.com/t/<thread_id>` | 官方路径路由 |
| Telegram | `web.telegram.org/k/#<peer_id>`（tweb hash 路由，同文档导航） | hash 不识别＝留在会话列表，**no-op 不是 404**；刻意不用 /a/（两变体登录态独立，跨变体会踢到扫码页） |
| WhatsApp | `web.whatsapp.com/send?phone=<E164 裸号>`（官方 wa.me 同款流） | 仅私聊数字号；**群 jid（…@g.us）被形态表拦下**回落「仅切标签」；整页重载数秒可接受 |

实现在 `desktop/renderer/thread-url.js`（thread 白名单消毒 + 平台级形态校验），随下一个桌面安装包到坐席机（1.0.24 若已封版则 1.0.25）。

## 7. 坐席怎么用

1. 工作台打开 tg / wa / msgr 会话 → 会话头出现 **驾驶权徽章**（「托管：工作台」蓝 /「托管：原生页」黄）+ **ⓘ 能力对照** + **「原生页打开」**按钮（桌面壳内才显示）。
2. 要人工用官方功能（打电话/转发/置顶）→ 点「原生页打开」直达同一会话；办完回工作台。
3. 要整个账号交给人工在原生页聊 → 点驾驶权徽章确认切「原生页托管」：该账号 AI 全自动即刻让位（待发草稿取消）；切回即恢复。
4. 纯浏览器（非桌面壳）打开工作台：原生按钮自动隐藏，徽章照常。
