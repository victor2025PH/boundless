## 二、录什么：聊天风参考音规格

1. **时长 12-20 秒**（低于 8s 韵律信息不足，高于 30s 无增益）。
2. **语体=微信语音闲聊**，照着「跟熟人随口讲一件小事」录，不是朗读：
   - 必须有：1-2 个语气词（嗯…/诶/吧/呀）、一处自然停顿换气、一处轻笑或笑意收尾；
   - 禁止：整句书面语、列表式罗列、广告/解说腔、连续排比。
3. **环境**：安静室内、离麦 20-30cm、无混响（衣柜/被子旁效果好）；44.1k/16bit wav。
4. **逐字稿 sidecar 必配**：`<名字>.txt` 与 wav 同名同目录、逐字一致（含语气词），
   7852 保真路径（zero_shot+逐字稿）靠它，错一个字都影响相似度。
5. 台词模板（可直接照说，替换括号内内容）：
   - 「嗯……跟你说个事儿哈，今天（做了什么小事），结果（一个小意外），
     哎我当时就笑了。反正……还挺有意思的，你肯定也觉得逗。」
   - 「我刚（在哪儿/干嘛）呢，等会儿还得（下一件事）。就先跟你说到这儿哈，
     回头……回头再细聊呀。」

## 三、换底流程（每个人设 15 分钟）

1. 录音 → 剪 12-20s 最自然的一段 → 存 wav + 同名 .txt 逐字稿。
2. **hub 侧（主路）**：在幻声 hub 上给对应「-智聊」档换参考音（或新建档），
   看档上 quality_axes：cosine ≥0.80 且 naturalness ≥0.83 才算过线。
3. `python tools/check_hub_voice_profiles.py` —— 核对 profile_map 全部命中（防 404 断档）。
4. **本地回落路径**：替换 `config/voice_refs/<persona>.wav/.txt`。
   预渲染库有参考音指纹生命周期（`_ref.json`），换底后夜间任务自动整目录重渲，
   急用可手动 `python scripts/avatar_prerender.py --all-personas --force`。
5. `python scripts/voice_similarity_probe.py` → 看 `logs/voice_similarity.jsonl`
   新样本的声纹/自然度分；再用 `/api/voice/tts-test` 合 2-3 句真台词人耳复听。
