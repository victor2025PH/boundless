# 授权分层与功能锁 · 运维手册（销售/实施一页通）

> 一句话：功能按档位卖（community / basic / pro / flagship），没买到的功能**看得见、
> 点得进升级页、拦得住、拦截还可计数**。
> 本页只讲操作与读数；行为契约以门禁为准（`tests/test_workflows_feature_flag.py` /
> `tests/test_feature_lock_stats.py` / `tests/test_feature_gate.py` /
> `tests/test_shop_link.py`），文档与代码冲突时**信门禁**。
> 关键事实由 `tests/test_licensing_runbook_doc.py` 钉住——改档位注册表/指标名而不改本页，CI 会红。

## 一、给客户开档位（三个开关，别混）

| 开关 | 配置键 | 语义 |
|---|---|---|
| 档位总闸 | `licensing.feature_gate.enabled` | `false`（出厂默认）＝全功能放行零变化；`true`＝按档位锁 |
| 生效档位 | license 文件的 `plan`，或 `licensing.feature_gate.plan_override`（灰度/自营用） | 优先级：override ＞ license（active/grace）＞ community |
| 模块 kill-switch | `inbox.workflows.enabled` | 运营自己关模块，与档位无关（关＝管理页 404、API 403「未启用」） |

- 正式客户：档位随授权文件签发，不手改配置。
- 演示机/灰度：overlay（`config.local.yaml`）写 `plan_override`，**免重启**（约 30 秒热加载）。
- 功能 → 最低档位的**单一注册表**：`src/licensing/feature_gate.py::FEATURE_MIN_PLAN`
  （当前 workflows=pro）。改表三件套：注册表本身 + 会员矩阵词条 `mb_feat_<族>` +
  重新导出功能矩阵文档（`python -m scripts.feature_matrix --out docs/功能矩阵_ChatX.md`）。

## 二、客户看到什么（锁定态三形态）

1. **侧栏**：锁定功能渲染 🔒 锁标，点击跳 `/membership?from=<族>`。
2. **直连 URL**（书签/分享链）：302 → `/membership?from=<族>`——会员页顶部横幅
   「你刚尝试访问『X』——该功能需要 Y 档位及以上解锁」+ 功能矩阵**对应行高亮** +
   「查看升级方案 →」购买按钮（chatx 产品族预选**目标档** offer；通译族/未知族回落
   按当前授权的深链；未配 `licensing.shop_url` 不出按钮）。
3. **API**：403 JSON（`error=feature_locked`）；工作台卡片（如「工作链执行」）收到
   403 **自动整卡隐藏**，坐席无感。

⚠️ 两种拦截话术**刻意分流**，别混：
- 档位不够 → 「当前授权档位未包含此功能，请升级套餐」（引导买）；
- 运营 kill-switch → 「工作流模块未启用」+ 管理页 404（部署选择，**不是**升级问题）。

## 三、看哪三个数字（`/api/workspace/metrics`，主管权限）

| 数字 | 在哪 | 怎么读 |
|---|---|---|
| `feature_lock.by_family` | metrics JSON + Prometheus `feature_lock_hits_*` | 谁的锁被撞得最多＝下一个该降档/该重点卖的功能。**只计 license 锁**，运营 kill-switch 的拦截不算（部署选择≠购买意向） |
| `rec_follow`（推荐跟随） | `GET /api/workspace/chain-funnel` + `/workspace/workflows` 监控页徽章 | 目标推荐链的采纳度。分母只算「模板有推荐链」的启动；某模板跟随率恒 0＝那对映射错了，改 `GOAL_CHAIN_REC`（sidebar-chrome.js 与 workflow_starter.py **两处同改**，等值门禁盯着） |
| `attr_reply_rate`（归因回复率） | 同上漏斗 `total` 段 | 挂在工作目标下启动的链 vs 散开启动的链，谁更能带来客户回话——「先建目标再挂 SOP」这套打法值不值，看它 |

## 四、常见问题

- **自营生产机为什么看不到锁**：overlay 是 `plan_override: flagship` → 全功能放行，
  锁定链路对内不可见属正常；验证锁定态用隔离实例切 `plan_override: basic`。
- **会员矩阵少了某功能行**：只有 `FEATURE_MIN_PLAN` 登记过的族才出现在矩阵。
- **workflows 页面直连为什么 404 而不是升级页**：那是 kill-switch 关闭形态
  （模块不存在于此部署）；升级页只服务「档位不够」。
- **在途执行会被锁停吗**：不会——闸门只拦「新动作」，运行中的客户跟进不因打包
  开关中断；要停用先在 `/workspace/workflows` 逐条取消再关。
