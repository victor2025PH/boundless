# 我的信用卡片 — 文案草稿与字段映射表

## 一、文案草稿（按区块）

### 1. 抬头
- **标题**：📊 我的信用卡片（或「信用名片」）
- **身份**：商户 / 普通用户（有则显示，无则省略）
- **更新时间**：数据更新于 YYYY-MM-DD HH:MM

### 2. 核心指标（醒目）
- **风险**：风险：低 / 中 / 高 / 极高（前可加 emoji：🟢 / 🟡 / 🟠 / 🔴）
- **信用分**：信用分：XX/100（可跟一句区间说明，如「80–100：整体较稳」）

### 3. 背书区（三列或三行）
- **账号历史**：官方 首次记录：YYYY-MM-DD（或「本系统记录 ≥ 1 年」简写）
- **交易成绩**：交易确认：成功 X 笔，成功率 Y%（无交易则显示「暂无交易记录」）
- **众包评价**：举报：共 Z 次（已核实 W 次）｜黑名单：否/是

### 4. 标签行（一句话）
- 示例：🏷 老账号 · 多笔成功交易 · 无黑名单
- 或：🏷 新账号 · 有举报 · 已列黑名单
- 无标签时：🏷 暂无标签

### 5. 底部说明
- **说明**：以上仅供参考，交易前请多核实、留凭证。
- **验真**：他人可点击「验真报告」并输入报告底部验真码核实本卡片对应完整报告。

## 二、字段映射表

| 展示项         | 文案 key（建议）     | 数据来源字段              | 备注 |
|----------------|----------------------|---------------------------|------|
| 标题           | sharecard_title      | 固定                      | 已有 |
| 身份           | sharecard_role       | label                     | 商户/用户，无则不出 |
| 更新时间       | sharecard_updated    | updated_at                | 需从 check 结果带出 |
| 风险           | sharecard_line_risk  | risk                      | 已有；可加 risk_emoji |
| 信用分         | sharecard_line_score | score                     | 已有；可加 score_hint |
| 区间说明       | sharecard_score_hint | score → 低/中/高          | 可选，如 80–100：较稳 |
| 账号历史       | sharecard_line_age   | first_seen                | 首次记录 或「≥1年」 |
| 交易成绩       | sharecard_line_tx    | tx_success_count, tx_total_count, tx_success_rate | 已有；无则「暂无交易记录」 |
| 众包评价       | sharecard_line_crowd | report_count, report_verified, blacklist | 举报共 X（已核实 Y）｜黑名单 |
| 标签行         | sharecard_tags       | tags                      | tag_* 转中文，用 · 连接 |
| 底部说明       | sharecard_disclaimer | 固定                      | 参考用 + 验真引导 |

## 三、API/服务层字段（get_sharecard_data 返回）

在现有基础上增加返回字段，便于 Bot 按上表渲染：

| 字段名               | 类型    | 说明 |
|----------------------|---------|------|
| tg_id                | int     | 已有 |
| username             | str     | 已有 |
| risk                 | str     | 已有 |
| score                | int     | 已有 |
| blacklist            | bool    | 已有 |
| tags                 | list[str] | 已有 |
| tx_success_count     | int     | 已有 |
| tx_total_count       | int     | 已有 |
| tx_success_rate      | float   | 已有 |
| first_seen           | str     | 新增，首次记录 YYYY-MM-DD |
| report_count         | int     | 新增 |
| report_verified      | int     | 新增 |
| updated_at           | str     | 新增，数据更新时间 |
| label                | str     | 新增，商户/用户等，可选 |

risk_dimensions 暂不放入卡片正文，仅保留完整报告；若后续要在卡片展示「四维简版」再扩展。

## 四、版式顺序（最终输出顺序）

1. 标题 + 身份（若有）+ 更新时间  
2. 空行  
3. 风险（emoji + 文字）  
4. 信用分（+ 可选区间说明）  
5. 空行  
6. 账号历史 | 交易成绩 | 众包评价（各一行或合并一行）  
7. 标签行  
8. 空行  
9. 底部说明 + 验真引导

## 五、实施与优化记录

### 已实现（相对初版的优化）

- **API/服务**：`check_by_tg_id` 结果中增加 `label`；`get_sharecard_data` 返回 `first_seen`、`report_count`、`report_verified`、`updated_at`、`label`。
- **Bot 版式**：在 `bot/format_result.py` 中新增 `format_sharecard(data, locale)`，按文档版式顺序生成整段卡片文案；`cmd_sharecard` 与 `cb_sharecard` 统一调用该函数，便于维护与多语言。
- **i18n**：补全卡片相关 key：身份（商户/普通用户）、更新时间、风险 emoji 文案、信用分区间说明、账号历史/交易/众包三行、标签行与无标签占位、底部说明与验真引导（中/英/ tl）。
- **无数据友好**：无交易时展示「暂无交易记录」；无标签时展示「暂无标签」；无 `first_seen`/`updated_at` 时对应行省略。

### 下一阶段可做改进

- **四维简版**：若要在卡片展示「身份稳定性 / 资金实力 / 社区评价 / 关联风险」简版，可在 `get_sharecard_data` 中增加 `risk_dimensions` 子集，在 `format_sharecard` 中增加一段简短展示。
- **分享统计**：记录卡片被查看/分享次数，用于「被查看 N 次」等信任背书。
- **PNG 卡片**：由服务端或 Bot 生成图片卡片，便于一键分享到社交平台。
