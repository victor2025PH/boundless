## 关键设计不变量（改动前先读）

1. **诚实边界**：无分段时间戳绝不伪造 SRT（`srt_reason=no_segments`）；贴回对
   identity 块（同语）跳过重绘；灯箱「看原图」切换＝坐席核对权不可删。
2. **qwen-vl bbox = 0-1000 归一化契约**（`parse_bbox_items` 缩放；spike 实证
   tmp_bbox_spike/）。
3. **`build_audio_transcribe_fn` 刻意不用全局单例**（`_pipeline_for` 按配置指纹）——
   RPA 嵌套 `audio_pipeline` 全是 enabled:false 死默认，全局单例首调定型会反杀翻译链。
4. **ASR 缓存信封 `ASRJ1:`**（P6）：带分段条目存 JSON 信封、纯文本旧值兼容；
   要分段但缓存没有 → 按 miss 重跑一次升级。坏信封＝miss，绝不当转写。
5. 多语言对照＝前端每语一次 `translate-compare`（后端零改动；计费按引擎×语言
   在服务端逐请求如实累计）；语言上限 3。
6. 媒体上传 b64 ×1.33 膨胀：中间件 body 上限必须 ≥ 路由级源文件上限×1.37
   （admin.py 四端点代码级缺省，config 可覆写）。
