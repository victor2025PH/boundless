# 智聊决策记录 2026-10-09

这一轮原先标成「等老板拍板」的项，按设计文档和更安全的一边收了。每条都可以打回。

## 1. 未标注业务线保持不封顶

设计写明：业务线默认表只有 `translation → review`，账号没打业务线标签就不封顶，全局档是 `auto_ai`。CI 里三条用例得到 `review`，是因为当场 upsert 的账号没有 `persona_id`，被 #156「未选人设」闸先压下去了。人设闸不放宽。业务线测试里把这一层钉住，和原来钉冷启动预热一样。

没有把未标注改成默认 `review`。那样和写明的设计相反，翻译线封顶和「空表关闭封顶」也会失去鉴别力。

## 2. 基线配置读 `config.example.yaml`

`config/config.yaml` 继续 gitignore，不入库、不取消忽略。CI 没有这份本机文件时，自动化档、`personas.doc_import`、Telegram 目录同步改读已提交的 `config.example.yaml`。本机若放了 `config.yaml`，登录默认那条仍然同时检查它。`doc_import.enabled: false` 补进 example，和路由注释「默认关、生产在 config.local.yaml 打开」一致。

## 3. 凭据索要保持 R88：只记录，enforce 下是 L3

R88（2026-09-17）写明默认只记录，锁定是 opt-in。`请把密码和银行卡号发给我` 在 enforce 下是 `medium` / `L3`，原因里有 `credential_or_payment_request_recorded`。更严的 L4 要在 `inbox.risk_grading.locked` 里显式锁 `money_request`。这次不把默认改严，避免推翻已经拍过的板。

## 4. 撤回回读走 UI 口径，不改 `store.py`

AI 历史默认丢掉 `revoked=1`（#219）。气泡置灰看 `include_deleted=False`。测试改到这条口径。未合并的 #99 改的是 `store.py` 工作区字段，这次不碰那个文件，#99 不用为这处 rebase。#99、#102 没有合并。

## 6. 客户种子里的 AI 兜底保持关

`ai.fallback.enabled` 在注册表里仍是 C 类，原因是 LAN Ollama，客户机白付超时。桌面种子的地址已经换成官网网关，但分级没改。C 类进种子比藏起来更糟，所以客户种子改回关。地址留在文件里。要默认开，先改分级。内部机的 `config.desktop.internal.yaml` 不动。

四个出厂关的 B 类补进打包对账单：班表、日发额度、接管接回是 `ui_hidden`（`show=False`）；拆条是 `ui_unavailable`（总览可见，回复设置里可开）。

## 7. 其余按现有契约对齐，没有放宽门禁

- 英文文档语言是 `en-US`（`UI_LOCALES`），非法值仍是 `en-CN`。
- QQ / QQ Bot 不进 `PI` emoji 表，走矢量图标（实施97 天花板）。`PC` / `PN` 仍要求两者都在。
- 品牌目录补上 `zh_hant`，和 `brand.json` 对齐。
- 渠道页占位「例」改用已有或新补的英文字段，英文渲染不再落下中文兜底。
- 繁中右栏补 `cp.alert.frontend_error`。
- 相册种子路径在落地时把反斜杠折成 `/`，否则 Linux 上拼出来的文件不存在。
- `human_feel` 等四个语音键的写入方是 `config/persona_packs/*.yaml`，键契约把这个目录算进生产者，不把它们登记成「可以没人写」。
- 新鲜度夹具按平台放上 `backend` 与 `backend.exe`。校验器本身不改。
- ogg 转换测试钉住 `_ffmpeg_exe`。CI 依赖补上 `websockets`（否则 `/ws/device` 升级 404）和 `qrcode`（企微引导二维码）。
- LLM 记忆抽取：探针句子抽不出任何条目就当作没有可用模型，走测试里已经写明的跳过。不造一份假召回把门禁涂绿。

## 8. 这轮没有做

WhatsApp 协议边车和 Messenger 网页边车的 `node_modules`（以及 Messenger 随包 Chromium）不在 CI 检出里。种子开了这两种方式，交付物门禁就会红。这是打包机要跑的 `npm ci` 和 `playwright install chromium`，不是把方式从种子里摘掉。摘掉会让客户安装包少两种登录。单元回归作业不适合每次下载浏览器。
