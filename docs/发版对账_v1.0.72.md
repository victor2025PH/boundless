## 二、公告口径（按 v2 写，老板 2026-09-04 改判）

- **全自动放行（#160）**：「AI 不再因为客户提到敏感词就停手。全自动就是全自动，触发到风险只做后台记录，一个月后我们用真实数据再定规则。」
  ⚠ **不得**写成「只在四种情况等人」——那是已作废的 v1 口径（`stop_contact` / `self_harm` / AI 稿 `reply_risk=high` / 客户索要凭证四条硬底线已全部取消）。台账 ops_only，坐席侧零改动。
- **审批页返回（#158）**：「草稿审批页顶部多了『← 返回聊天』，点顶栏『聊天』也能回到收件箱了（之前在桌面版里点了没反应、只能关窗）。」
- **语言铆定（#154）**：「会话设了『发→X』就永远发 X，对方换什么语言都不动；铆定不再被程序悄悄清掉。你在会话里看到的『我方消息对照行』现在按你设的『收→』语言显示，不再跟着对方刚切的语言跑。」
- **语音 / 未读 / 人设**（对话 B 部分）：
