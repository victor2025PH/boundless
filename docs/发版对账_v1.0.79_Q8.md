## 〇 为什么 AI 会「四轮纯夸赞后自己退场」（三段）

1. **没目标就没方向**：B9D8NW / 7C7SV2 / R6YW5D 三包里 7 条 `profile_discovery` 全是手建，Enrique 这类新客没人建 → 每稿 `goal-inject NOT injected reason=no_goal`，prompt 里只有人设没有「这轮要推进什么」。
2. **有目标也只是「软提示」**：O-3 C 的「【本轮必问】」只在 decide_probe_target 选出槽时出现，客户连发 "so beautiful / wow / 😍" 这类零信息回合，模型顺着夸赞回应两句就结束——没有「不许只回应夸赞、必须问出去」的硬约束，也没有「换你来带话题」的替代动作。
3. **退场句没人拦**：`commitment_guard` 只管「我等下发你 X」类承诺，"gotta go / get back to work / talk later" 这类**自己结束对话**的句子畅通无阻；工作时段内、客户没告别、用户没开留白策略，AI 却替坐席下班。
