## 设计取舍（深想后的三次改向）

1. **核心逻辑不写进 PowerShell**：规格只钉了 `.ps1` 接口——保留接口做薄壳，逻辑下沉
   Python 核心，排除规则/快照/校验全部进 pytest 护栏（PS 里这些只能靠人工演练）。
2. **denylist 而非 allowlist**：本周刚新增 compliance_*.json、sticker 等新 store——
   allowlist 会随新 store 静默漏备；denylist 只登记「确定不要的」，新数据默认被保护。
3. **放弃无人启动验证**：曾考虑恢复后在本机起隔离实例验 GO——判定风险不可控
   （恢复根带生产 Telegram 凭据，禁用键无既定模式，猜错=劫持生产会话互踢）。
   改为「完整性 + 行级抽查」强验证；启动 GO 属换机现场第 6 步（SOP 写清判据）。
