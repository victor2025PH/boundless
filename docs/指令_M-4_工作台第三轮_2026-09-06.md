## 2. A —— 幽灵未读口径统一 + 存量清理（#222，P2）

**事实**（GQREHD / FF5PGS）：steven 头像角标 5 / 账号切换器 5，私聊列表（筛选 私聊 + 账号）零未读；同账号 群组 11 / 频道 2 / 已归档 16；被埋会话 7→8→9、最老 100h；群/频道 `AutoDraft skip_groups=True` 只进不出。

**修法**：
1. **同一口径**：角标数 = 当前列表筛选范围内的未读（私聊视图就只数私聊），或角标旁标「含群 N / 频道 N / 归档 N」——二选一，落点表写明选哪个（建议前者 + 悬浮明细）；`/account-unread` 浮层与角标同一 WHERE（`verify_account_rail_ui.py` 场景 13 已钉恒等，扩到筛选维度）。
2. 群 / 频道未读：`skip_groups=True` 的会话未读不计入角标（或单列一格「群 / 频道 N」），并在群会话行显示「AI 不处理群消息」说明。
3. **存量一次性清理**：装载后启动清扫把「人工归档 + 无入站 > 72h」的被埋未读标已读并落日志（`[buried] startup_sweep cleared N`），同时保留 L-3 B 的横幅给 <72h 的。
