## §F 先答一问：派发循环到底跑没跑（写在最前）

**结论一句话：循环从 13:14:52 起一直在跑、每 600s 一拍；`enabled=False` 是「空转」不是「不启动」；15:27:31 运行时切开关在内存里即时生效；「零 tick 日志」是设计如此（无事可派的 tick 一个字都不写），不是循环死了。真正断掉的是后面两层：`bring_forward` 之后那 50 分钟没人能从日志判断循环看到了什么（无 tick 日志），以及 16:34:52 入队的 deferred 队列**根本没有 drain loop**。**
