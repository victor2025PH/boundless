## 回答 skuio「KB / 技能检索对拟稿零贡献」

1. `hits=-` **不是 KB 命中**：那是回复日志里的风控命中词字段（#187 已按误读关单）。KB 是否进过 prompt 看 `kb_query_log.hit`（现在 ops 📚 卡直接显示「近 7 天注入命中 N / 检索 Q 次 / 最近一次注入时刻」）。
2. skuio 机的 KB **很可能只有 110 条厂商预置、0 条用户条目**——装 1.0.74 后 ops 卡会显「用户条目 0 / 厂商预置 110（已从对客检索硬排除）」+ 黄字「用户知识库为空——AI 拟稿只能靠人设与对话上下文」。这句话就是对「零贡献」的正面回答：不是检索坏了，是没有他自己的知识可检索。
3. 他要 KB 有贡献：`/knowledge` 一键清空厂商预置 → 添加自己的条目（触发词贴近客户原话）→ 「已向量化」应随之增长 → 7 天后看命中数。
4. 若装后显「有 U 条用户条目却 7 天零命中」黄字，则才是检索侧问题（触发词/向量化/kb_gate 阈值），再开单。
