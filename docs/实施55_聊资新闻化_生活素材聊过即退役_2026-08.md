# 实施55 · 聊资新闻化：生活素材「聊过即退役」+ 实时新闻为主 + 按人设国家分源

> 2026-08-22 11:00 老板拍板：「所有的人设聊过的生活素材就不要再聊，要以最近实时的
> 新闻、娱乐等为主。接近生活的本土和人设所属国家的社会新闻。」
> 本批全部 `.py` 改动搭下一个重启窗装载；overlay 配置已热生效（旧代码忽略新键无害）。

## 一、拆解与机制映射

| 老板原话 | 机制 |
|---|---|
| 聊过的生活素材不要再聊 | **会话级已用账本**（新 `src/companion/life_beat_ledger.py`）：life_share 真发 + 聊天回复真提及 双入口记账 → `pick_life_beat(skip_fn=)` 逐会话排除，全用完＝生活线让位 |
| 以实时新闻/娱乐为主 | 既有 `daily_topics`（RSS→缓存→注入）提频 + 主动开场 `news_share` 开闸并**升格到 life_share 之上**（`proactive.upgrade_life_share`） |
| 本土/人设所属国家的社会新闻 | **按人设分源** `region_feeds`：键=人设 id（城市级本土源）或居住地国家码，区域独立缓存独立刷新，冷启动回落全局池 |

## 二、改动清单

### 新增
- `src/companion/life_beat_ledger.py`：会话级素材账本（`AITR_DATA_DIR/config/
  life_beat_used.json`，有界 600 会话×128 条，落盘幂等）+ `beat_mentioned`
  提及判定（CJK bigram/拉丁词重叠，min_ratio 0.20 + min_hits 3——改写型转述
  实测重叠 0.25-0.35，通用词「今晚/晚上」不误标）+ `convo_key_from_context`
  （conversation_id 优先，回落 platform:acct:chat，与两线既有键同格式）。
- `tests/test_life_beat_ledger.py`（9 例）。

### 生活素材退役链（三接线点）
- `deep_persona.pick_life_beat(skip_fn=)` / `build_life_beat_opener(skip_fn=)`：
  已用素材不进池；全用完 → None/{}（**顺带修**：`build_deep_persona_block` 的
  `deep_ctx or {}` 对空 dict 换新对象丢引用 → 改 isinstance 判断）。
- `ai_client._build_context_prompt`：注入生活线时挂会话排除闭包 + 把选中素材
  栈进 `context["_life_beat_current"/"_life_beat_ck"]`（先清残留再落键）。
- `skill_manager._update_after_reply`（A/B 两线单点收口）：回复**真提及**本轮
  素材 → 记账退役；`mark_life_share_sent(beat=)` 主动分享真发也记账；
  `_life_beat_opener` 传排除闭包。

### 新闻为主（消费面两条链）
- 聊天注入（`_inject_reply_freshness`）：`offer_percent` 可配（默认 15=旧行为，
  overlay 35）+ 按人设分源选缓存（区域冷启动回落全局池）。
- 主动开场（`proactive_topic`）：`news_upgradeable_modes(config)` 单一事实源——
  默认 gentle_checkin/weather_hook（旧语义）；`upgrade_life_share: true` 时
  **life_share 也让位**（新闻有货即优先，预写素材降为新闻无货/72h 频控窗内的
  补位）；`_news_opener(persona_fn=)` 按人设分源 + 区域缓存背景保鲜。

### 配置
- zhiliao overlay（已热生效）：`proactive.enabled: true` + `upgrade_life_share:
  true` + `offer_percent: 35` + `cooldown_hours: 2` + `region_feeds`（lin_xiaoyu=
  哈尔滨搜索源+国内社会/娱乐；CA/US/ES/TH/PH/HK=当地版 Google News + 家乡中文闻；
  国内人设走全局池不变）。
- `config.example.yaml` 注释文档同步。

## 三、安全与口径（刻意为之）

1. **轻话题闸不动**：主动开场仍走 `smalltalk_topic` allowlist（军政财法灾一律
   不当寒暄，2026-08-04 霍尔木兹群发实锤防线）；「社会新闻」的重口部分只在
   **反应式**（客户主动问新闻）时可聊。
2. **提及判定偏灵敏**：错标＝素材提前退役（代价低，方向正确）；漏标＝复读
   （老板正在骂的）。min_hits=3 挡通用词误标。
3. **区域缓存冷启动回落全局**：宁可聊全局新闻也不空手；区域 feed 配错/挂了
   不伤链路（fetch 软失败 + 全局兜底）。
4. **账本落点 env 感知**：`AITR_DATA_DIR` 存在按它解析（生产=实例数据根、
   测试=conftest 进程级 tmp，绝不写仓库 config/）。
