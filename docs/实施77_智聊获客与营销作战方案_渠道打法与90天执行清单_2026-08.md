  WA Business API 采用量 **24 个月增长 340%**。
- Click-to-WhatsApp 广告按购买优化：**销售 +1.8 倍、单次购买成本 -40%**（Meta
  官方越南案例）；印尼实测 CTWA 把 CPL 打下 40-70%。

- **给销售话术的弹药**：客户不需要被教育「聊天里能成交」，需要被告知「你的同行
  已经这么干了、你缺的只是接得住的工具」。

## 三、获客飞轮：把自家武器接成一条流水线

```
[找到人]                    [聊起来]                  [转化]                [裂变]
MatrixX TG群搜索/成员提取 →  智聊 AI 人设承接         →  6U 新人包/免费开始  →  L1 分佣裂变
huoke FB群提取/加好友     →  多语拟人互译             →  官网 ?ref 归因订单  →  邀请里程碑（已有）
蝴蝶号/内容评论区导流      →  主动触达(proactive)      →  小界顾问收口       →  成交客户转代理
TG Ads/CTWA 付费流量      →  语音克隆增强真人感        →  chatx-funnel 埋点   →  案例素材反哺内容
```

**全链路都是现成代码**：orders 的 `ref`（AI 会话归因）+ `utm_source`（渠道归因）、
chatx-funnel/intro-funnel/trial-paid-funnel 埋点、频道日更、小界顾问、防编造闸——
本方案 90% 的「工程」是运营配置，不是写新代码。

**红线先立**：自获客动作全部走既有风控护栏（账号 kill-switch、频控、ban_signal），
把「获客烧号」当成本科目管理：每周盘点账号损耗率，损耗成本计入 CAC。gated 高风险
产品线（智控 MatrixX 本体等）**不进任何公域投放素材**——它是我们的获客工具，
不是公开卖点（对外只讲智聊）。

## 四、渠道打法（按 ROI 优先级，每条给动作/成本/预期/节奏）

### 🥇 渠道一 · TG 生态自获客（成本≈电费，本周就能开）

**动作**：
1. 用 MatrixX 群搜索扫「跨境电商/出海/独立站/TG 营销/东南亚华人」中文群 Top 200，
   成员提取入库（目标池 5-10 万人）；
2. 智聊 AI 人设分批加好友+打招呼（复用 proactive 全套 pacing/退避/opt-out 护栏，
   日加严守频控），人设定位「出海获客顾问」而非硬广机器人；
3. 承接话术钩子（按优先级 A/B）：「外语询盘用母语级翻译回」「免费版标准翻译
   不限量」「6U 新人包」；聊到意向 → 发官网带 `?ref` 深链 → 订单自动归因结算；
4. 同步把这批人导入**自有 TG 群**（频道已有日更，补一个交流群），群内小界 bot 答疑。

**成本**：账号损耗 + 电费。**预期**：以 3% 加通过率、加通过后 5% 到站、到站 10%
注册计，5 万池 ≈ 75 注册/轮；真实数字以首轮 500 人小批校准后再放量。
**节奏**：周一批号/选群，周二起日跑，周五盘损耗与转化，周报进 ops。

### 🥈 渠道二 · 微信私域 + 蝴蝶号（中文卖家的信任主场，零投放）

**动作**：
1. **专用微信号**（1-2 个）通讯录只加跨境卖家（来源：知无不言互动、行业群互换、
   线下会、客户转介绍），绑定视频号；
2. 视频号内容=「出海获客实操」垂直号：外语询盘实录改造、AI 接单过程录屏、翻译
   对比评测（严守防编造纪律——现有 `looksFabricated` 闸的规则平移到人工内容审）；
3. 企微承接 + 标签化（意向/平台/规模），朋友圈每周 3 条经营（案例、更新日志、
   限时新人包）；
4. 公众号开号发长文（周一篇），全部按 GEO 结构写（见渠道四）——微信搜一搜 +
   AI 搜索双收录。

**成本**：人力（老板/运营每天 1 小时 + AI 代笔初稿）。**预期**：蝴蝶号打法外贸圈
实测 14-28 天出首询盘；私域用户 LTV≈公域 3 倍。
**节奏**：视频号周 3 更（AI 生成初稿+录屏，单条制作 ≤1 小时）、公众号周 1 更。

### 🥉 渠道三 · 知无不言 + 垂直媒体（借圈层信任）

**动作**：
1. 注册实名账号，前 30 天纯输出干货（外语询盘承接/多语客服 SOP/AI 工具评测），
   积威望值——该社区「内容为王」，硬广直接死；

4. 预算允许时谈广告合作位（雨果网/卖家成长同理，先内容后广告）。

**成本**：会费+时间；广告位另议。**预期**：单篇优质帖在社区+微信群转发的长尾
线索持续数月；目录入驻带来「主动找上门」的高意向询盘。

**⑥ ⚠ 部署顺带引发并已修复的事故：官网部署把桌面自动更新指针打回旧版**

- **现象**：本批部署的 `[3.5/4] 同步 public/downloads` 步骤上传了 `latest.yml`，把生产的

- **根因（是机制问题，不是手滑）**：`deploy.ps1` 对 `public/downloads` 的语义是「**本地

  发布到服务器与 R2 时没有把 `latest.yml` 回填本地树（本地停在 1.0.57，且确认是 LF、

  发布指针**，而部署脚本全程零提示。
- **判据（三个独立来源互证 1.0.58 才是应发版本）**：`desktop/package.json`=1.0.58、
  服务器 `manifest.json`=1.0.58、`announcements.json` 公告「v1.0.58 已发布…建议尽快更新」。

  待办提示。语法已校验。
