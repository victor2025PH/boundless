## 2. 三视角

### 2.1 开发工程师视角——「这些不是 20 个 bug，是 8 个结构性缺口」

1. **发版渠道断层（最重要）**。「出厂开」决策（D1 `companion.goals.sprint.enabled`、D7 `companion.wellbeing.crisis_audit/escalation`）只写在 `config/config.desktop.internal.yaml` → 打包时 `stage_internal_assets.py` 复制为 `build/seed-data/config.local.internal.yaml` → 只进 **smart 内测包**；`_ensure_seeded_extras`（`config_manager.py` L284–319）在客户机首启用 `_merge_missing` 补键。但 `publish_chatx.ps1 -DistDir dist-clean` 发布的、`latest.yml` 指向的、两位内测人点「立即更新」拿到的，是 **495 MB 干净包**，`resources/seed-data` 不存在 → 整条种子链 no-op。结果：1.0.74 在 skuio 机 00:22/00:27 两次 boot 均 `sprint.enabled=False`，且 J-2 新加的 WARNING 正在忠实地告诉他「自动推进不会主动出手」。危机留痕同理。**只要这条不修，以后所有「内测机出厂默认」决策都会重演。**
2. **桌面包携带内网默认值**。`gpu_watermark.py` 默认 `192.168.0.140:11434`、`voice_transcriber.py` / `avatar_voice.py` 默认 STT `192.168.0.140:7854`、`spoken_style_bridge.py` 默认 `192.168.0.173`；`health_watchdog` 每 5 分钟探 LAN GPU。客户机上这些永远不可达 → 「LAN GPU 两台不可达 30 分钟本地冗余归零」红 toast、Embedding 熔断（→ 学习队列相似度退化为常量 99%）、转录双级返空（09-06 00:51 起）、翻译主节点掉备点（→ #176 元回复）。桌面形态应**只认官网网关**（`hosted_gateway.py` 已有这一层），LAN 项在 `desktop_mode` 下不注册、不探测。
3. **识图网关缺 `num_ctx`**。`website/lib/ai-gateway.ts` 把识图请求转给中继机 Ollama `qwen3-vl:8b-instruct`，未带 `options.num_ctx`，Ollama 缺省 4096；识图 prompt + 一张图 ≈ 4170–4181 tokens → 必 400。`vision_client.py` 兜底智谱 GLM-4V 的令牌已过期 → 双败。服务端改一行（`num_ctx: 8192` 或 Modelfile `PARAMETER num_ctx 8192`）+ 换令牌，**不需要发桌面包**。
4. **状态机不闭环**。「需人工」只有 `tag_needs_human`（`autosend_worker.py` L528–578，reason=dup_guard_blocked）和 `clear_needs_human`（`protocol_autoreply.py` L783，仅人工发消息）两个动作，AI 自动回上、客户消息被消化、会话被归档都不摘标；打标带 `{reason, ts, source}` 元数据却没有在会话头部展示。幽灵未读：`HealthWatchdog(alert_on_warn=False)` 让「被埋会话 8 个 86h」永远只写日志；J-4 A 做了入口但没做「入口可见性回归」（skuio 用了 1.0.74 一夜没找到）。断线弹窗：`notify-bus.js` 只有 `snooze 1h`，无按账号静默 / 停用态 / 合并计数。
5. **出站形态被当成「节奏参数」而不是「可信度参数」**。`reply_split.py` 的 `per_sentence` + `max_parts=2` 在 skuio 机是开的（谁开的无记录），效果是「一句一条、条间 6–15 秒」，恰是客户描述的「打字方式和 WA 不一样」。镜像层 `_send_bubbles` 只记原稿一行 → 坐席无从发现。`GreetingSkill` 逼模型编「今日近况」（无档案/无天气源 → 幻觉），且编出来的内容进 `_conversation_history` 被当事实复用——这与 #171（谎称发图）/ #175（客服腔）是同一类「出站承诺/事实校验缺位」，J-1 只堵了两个词表，没有通用的「出站事实来源标注」。
6. **人设/语音配置模型把实现细节暴露成用户界面**。`voice_profile.backend`（五个引擎枚举）+ `voice` 手填 + 无「backend 与 voice 类型匹配」校验 → Mizuki `avatar_clone + ja-JP-NanamiNeural`；回落链在克隆失败时**换到默认预置声**（性别都不对）而不是「降级为文字 + 提示」。`personas.html` 基础 tab 的 JSON 导入块在 1.0.74 被改成默认展开（哪条 commit 改的要查——K-2 落点表没提，疑 J-7 B/D 顺带），`解析并填充` 直接写字段。`binding_count` 与 K-2 A 的 `collect_binding_usage` 两套口径并存。
7. **后台没有「给谁看」的维度**。`nav_schema.CLIENT_HIDDEN_ITEM_IDS = ("logs","developer","bug_tickets")` 是唯一的 flavor 门（L565 `hidden_ids |= …`）；`settings.html` 的白标 / 演示数据 / 授权、`help.html`、回复策略、`reply_settings.html` 高级三块、`learner.html`、`singing.html`、`voice_eval.html` 全部对 client flavor 直出。机制已有，只是清单没维护、也没有「运营/代理商」第二层。
8. **登记链靠人**。field-agent 上传 → VPS `uploads.jsonl` → `duty_watch_loop.py` 拉到 `tmp_diag/` 就停了，立不立单全靠值守对话手写脚本（09-05 三次脚本立了 29 份、漏 28 份）。bot 的 smalltalk 判定把「先列出41张单以及修复的结果」静默；序号哨兵不认自己账号经 send 路径发出的消息（mid 1224 → 假 P1）；`/reply` 端点无 reply_to。

### 2.2 市场经理视角——「客户在替我们做黑盒测试，而且开始不信了」

- **核心卖点正在被真实客户证伪**。产品卖的是「AI 像真人陪聊」，而 09-06 00:37 客户 Sceya 的原话是 *I got scared cause sometimes I feel you're not real … there's really a huge difference between your typing here on TG and WhatsApp*（#210）。这不是内测人的意见，是付费用户的客户的直接反馈。同族：男人设对客户发女声（#205 兜底）、AI 说「刚发了照片」实际没发（#171，1.0.74 已修待验）、陪聊人设冒出「我的助理会联系您」（#175，同）、AI 否认自己刚说过有女儿（#177，同）、问候编造下雨（#208）。**优先级第一位的永远是「别让客户识破」**：拆条默认关、兜底不换声、不编事实——比任何后台美化都重要。
- **「已修复」的口碑成本**。skuio 昨晚提交 42 项，凌晨发现 28 项没人理，今天用 44 项总表逐条对账，统计出「完全修复 0」。他没错——1.0.74 的 49 项是「代码到了、没人告诉他验什么」，而他真正在意的 20 项没排进去。**回访与 changelog 对账**（K-5 ④⑤）现在是信任问题不是流程问题；同时要把「已修复」的门槛提到「内测人复验通过」（K-D2 精神）。
- **空壳功能是售前减分项**。歌房（曲库 0 / 声库 0 / 开关却开）、声音评测（没有生产入口）、帮助中心「客服培训演示」点开 JSON 报错、系统设置「授权：社区模式」与右上「旗舰版」互相打脸——任何一次给代理商/客户演示都可能撞上。原则：**没准备好的功能不出现在用户版菜单**，出现即要么可用要么写明「升级中/联系客服开通」。
- **分层缺失既不专业也泄露商业结构**。品牌/白标是代理商/OEM 卖点，终端用户看到「可改产品名去厂商署名」= 白送；试用/演示数据一键铺假会话在全自动账号下会**真发出去**。需要用户版 / 代理商版 / 研发版三层可见性，且演示数据只对空工作区开放。

### 2.3 用户视角（skuio / 钧）——「我报了，你们没回；修了，我看不见；页面全是我看不懂的词」

- **信任**：「昨日提交 42 项，1.0.74 状态：完全修复 0」（C6EFRS）。他不知道 49 项修了什么、也没人告诉他 28 项根本没排进去，直到 09-06 03:43 才有人认账。**每一份报告都要有单号回音**，「收到 N 份」等于没收到。
- **看不见因果**：手机端两条、工作台一条（#210）；角标数字 1 和 2 却找不到未读（#170）；「需人工」红标点进去什么都没有（#207）；发视频弹「后台重启中」但后台没重启（#194）；试听三次三个声音（#205）。用户的判断依据只有界面，界面说谎或缺口，他就只能报 bug。
- **看不懂的词**：BACKEND / VOICE ID / 向量·句向量·实体别名 / R4→R6→R8 / Temperature·Max Tokens·上下文轮数 / 意图→策略映射 / 缺依赖·未开放 / `/setrate ch1 0.05` / `personas.yaml`。他反复问「这是什么意思、是不是给开发者的」。
- **操作成本**：学习队列 166 条外语原文无译文 + 「全部通过」一键；325 张相册卡片（1.0.74 已改）；平台覆写表默认展开；人设节奏表要填人设 ID。
- **浪费时间的空壳**：歌房 / 声音评测 / 培训演示——点进去以为坏了，再花 20 分钟取证证明它「没坏，只是空」。
- **钧的诉求更短**：表情破图、识图不可用是每天遇到的（#195/#213）；他要的是「照此执行」式确认和一句话原因，不要过程。
