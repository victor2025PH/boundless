## 1. 背景与调研结论（2026-08 最新）

现状：球是 46px 静态渐变按钮，动态信号只有 busy 阴影脉冲和红点；录音无任何音量反馈。

调研主结论：头部玩家（Apple Intelligence/Siri、ChatGPT Voice、Gemini Live、Rive orb 生态）的 orb 全部是**带音频反应的状态灯**而非装饰，状态集合一致（idle/listening/thinking/speaking/success/error），且遵守「**动画就是状态 API**」——工作时出现、思考时变奏、出结果即熄，绝无常驻花活；reduced-motion 一律退化为透明度脉冲。技术选型上 46px 塞不下粒子 → **双尺度**：46px 能量核（纯 CSS 极光）+ 活跃态 168px bloom 光晕（Canvas 2D 粒子），Rive/Lottie/three.js 全部不引（违单文件零依赖纪律 + 烤死颜色破坏白标）。

## 2. 四视角要点（详版见会话记录，此处存决策要点）

- **用户**：球=用余光可读的状态灯；录音波形消解「它听见没有」的不信任；待机呼吸幅度 ±1.5%/7s 低于分心阈值；安静模式 + reduced-motion 兜底 8 小时班的疲劳。
- **市场**：orb 是「自带 AI 员工」定位的脸面；≤15s 录屏即演示素材（对球说话看涟漪/星系思考/粒子对勾）；全令牌化=白标 OEM 免费获得品牌色 orb；铁律=低配机上不许卡。
- **UI/UX**：一套「活物隐喻」动效语法（呼吸=活着/涟漪=听见/旋涡=思考/爆闪重组=办成）；效果必须在真实 46px 验收；面板头像迷你核镜像同态=球↔面板视觉连续。
- **工程**：单文件自治不破；待机 0 JS 帧；rAF 只在活跃态跑；调速器只降不升；每个动效映射真实状态源。

### 3.1 状态机（真实信号驱动，无一装饰）

| 状态 | 信号源 | 视觉 |
|---|---|---|
| idle | 无活动 | 径向底盘（accent 令牌随白标）+ 双层旋转极光（conic 伪元素，9s/5.5s 反向）+ 呼吸辉光 7s |
| hint | 工单有新回复（hasdot） | idle + ping 涟漪环（30s 周期 ×3 次，纯 CSS） |
| listening | REC 录音中 | hue-rotate 转青 + **大 bloom 168px**：声波涟漪环（RMS 触发）+ 粒子环（低/中/高三频段各管 1/3 粒子半径抖动）；录音按钮实时电平圈 |
| thinking | S.busy（问答/转写在途） | hue-rotate 转紫 + 星系旋涡（椭圆轨道 30-42px 环绕球缘），流式 delta 到达即加速（把 token 流可视化） |
| alert | nudge 冒泡在场 / 查询失败（2.6s 瞬态） | 琥珀径向脉冲叠加层 |
| success（一次性） | 报障提交成功 | 粒子从环位飞散重组成**绿色对勾**盖在核面（950ms 自终结；目标点=离屏对勾字形像素采样） |

优先级：listening > thinking > alert > hint > idle；面板头像 `.asb-hd-ic` 经 `.asb-panel.st-*` 镜像同色。

### 3.2 三档画质与调速器

- **lv0**：静态渐变+透明度脉冲（`prefers-reduced-motion` 强制此档，Apple 同款降级语义）。
- **lv1**：纯 CSS 极光（合成器动画，0 JS 帧）——「动效：安静」档。
- **lv2**（默认，= zhiliao 拍板档）：+Canvas 粒子（Float32Array ≤128 颗、rAF 循环零分配、DPR 封顶 2、`visibilitychange` 即停、暗/亮主题自动切 lighter/source-over 合成）。
- 档位解析：`localStorage asb_orb_lvl`（admin 工具行「动效」按钮）→ `boot.orb_level`（后端旋钮**预留**，bootstrap 暂不下发）→ 默认 2；reduced-motion 恒压 lv0。
- **调速器只降不升**：帧时长 EMA>26ms 持续 → 先砍半粒子 → 再超 → 本会话降回纯 CSS；`asb_orb_degrade_half/css` 打进 `/api/telemetry/ui-event`（file:// 夹具自动跳过）。
- 待机**零 rAF**：canvas 只在 listening/thinking/burst 存活，其余时间连元素都不解锁（懒创建）。

### 3.3 音频管线

`orbAudioStart` 复用既有 `REC.stream`（AudioContext 在用户手势内创建；停录 `suspend()` 复用不重建）；AnalyserNode fftSize 256 / smoothing 0.72；人声频带 RMS + 自适应底噪/峰值归一化；attack 检测触发涟漪。无分析器（能力缺失/夹具态）回落柔和合成波保住「在听」语义。**顺手关掉真实 UX 缺口：录音期麦克风按钮长出实时电平圈**——此前只有按钮变红，用户不知道系统听没听见。

## 4. 实施中的深想优化（相对原方案的增量）

1. **P0+P1 合并一批出货**——纯前端热更让「状态灯」与「粒子声波」没必要拆两期，快赢更快。
2. **状态换色统一走 `filter:hue-rotate`** 而非换渐变——可过渡动画（0.5s 平滑变色）、合成器友好、白标 accent 底盘自动跟随，一举三得。
3. **爆闪期画布临时提到球面上层**（z-index 1→3→还原）——截图实测对勾被 46px 球体挡住只露边，「盖在核上」才可读；listening/thinking 光晕仍在球后（正确的层次语义）。
4. **思考旋涡轨道 14-27px→30-42px + bloom 0.55→0.7**——同一轮截图实测旋涡整个藏在球后不可见；「效果必须在真实尺寸验收」这条 UX 军规当天就抓到两个设计位错误。
5. **token 流可视化**：thinking 无音频，用 SSE delta 到达节奏驱动旋涡加速——比假波形诚实。
6. **AudioContext suspend 复用** + 分析器停录即拆——防泄漏防重建开销。
7. **调速器带 1.6s 迟滞 + 会话内单向降档**——防档位抖振；降档必打点，低配机受苦看得见。
8. **`_orbForce/_orbBurst` 调试钩子**与真实信号共用同一条 `syncOrb` 通路——门禁/演示页驱动状态零旁路，不会测一套跑一套。

## 5. P2「开口与协奏」实施记录（同日 03:34，VER=20260823b）

原 P2a/P2b/P2c 大部分**当日提前落地**——实施中深想后发现无需等实施58 P3：TTS 全栈早已在
（`/api/voice/tts-test` + `__system__` 系统音色哨兵），「小智开口」纯前端接线即可闭环。

1. **speaking 播报态**：每条 AI 回答尾部 🔊 按钮（逐条点击 opt-in，绝无自动播报）→
   `POST /api/voice/tts-test {persona_id:'__system__', fast:true}`（系统音色=身份边界，
   小智绝不用人设克隆声；fast=常热 edge 引擎零 GPU 占用）→ `<audio>` 经
   `createMediaElementSource` 接同一 AudioContext → **球缘径向均衡条随 TTS 频谱起舞**；
   合成失败=诚实红气泡；点录音自动停播报（防扬声器进麦回声）；ended/error 自复位。
2. **面板 voice-hero 波形条**：聆听/播报期输入区上方全宽实时频谱（对称条，青=听/紫=说），
   与球共用同一 rAF 与分析器读数，零独立循环；面板关/状态退即收。
3. **orbMode 公共 API**（`AssistantBall.orbMode('teach'|'agent', on[, 进度0..1])`）：
   teach=青色雷达扫描环（纯 CSS 态）、agent=彗星轨+可选进度弧——供实施58 教学/代办线
   一行接入（该线已声明零碰本文件，自建 assistant-teach.js/assistant-agent.js，正好经此
   API 协奏）；黏性模式参与正常优先级，**真实信号（听/说/想）永远压过模式**。
4. **workspace 壳「动效」档**：工具行不再整行隐藏，保留唯一的「动效：饱满/安静」按钮——
   8 小时盯屏的坐席拿回注意力权（原 P3 项提前）。
5. **后端旋钮 rider**：bootstrap 下发 `assistant.orb_level`（0/1/2 夹紧；缺省不下发=前端
   默认 2；本地偏好与 reduced-motion 永远更高优先）——`.py` 随下个重启窗装载，装载前
   前端行为不变（中间态自洽）。example 配置注释键已登记。
6. 验证：`verify_assistant_ui` 40/40（新 O6-O9：speaking+hero/teach/agent/播报诚实失败路径；
