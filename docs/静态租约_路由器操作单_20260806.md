## 步骤（TP-Link 企业系网页版）

1. 浏览器打开 `http://192.168.0.1` → 输入管理密码登录
2. 找 **基本设置 / 网络设置 → LAN 设置 → DHCP 服务**（不同固件叫法略异：
   「静态地址分配」/「地址保留」/「IP-MAC 绑定」）
3. 逐行添加上表 6 条：MAC 填表中值（格式若要求冒号分隔就把 `-` 换 `:`），IP 填绑定 IP
4. 保存。**不用重启机器**——当前 IP 本来就与表一致，租约只是把它焊死
5. 验证（任一即可）：
   - 中枢跑 `python D:\boundless\tools\machines_lint.py --remote` 应全绿
   - 六机桌面壁纸保持正常（若哪天出现紫色「本机 IP 漂移」横幅=租约没生效）
