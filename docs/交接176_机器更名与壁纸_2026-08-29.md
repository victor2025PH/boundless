```powershell

```

SystemParametersInfo 立即刷新、`Rename-Computer`（待重启）。

不便拉文件的话，两条手工命令等价（壁纸文件先放好）：

```powershell
Set-ItemProperty 'HKCU:\Control Panel\Desktop' -Name Wallpaper -Value 'C:\zl_wallpaper.png'
Rename-Computer -NewName ZL-SHIJUE -Force
```

顺带说明：117 尝试直连你被拒（`Permission denied (publickey)`——你机器上没有 117 的
公钥，这是你们侧的安全边界，不是故障）。若愿意开免密，把 117 `C:\Users\Administrator\.ssh\id_*.pub`
加进你的 `authorized_keys` 即可，后续这类批量运维就不用麻烦你了。
