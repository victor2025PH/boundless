## 4. A —— 平台登记 + 账号地区模型（P0）

**修法**：
1. 新建 `src/integrations/tiktok_regions.py`：纯数据 + 纯函数。`DM_API_UNAVAILABLE = {EEA 30 国, CH, GB, US, IN}`、`MEDIA_SEND_UNAVAILABLE = {AU, CO, EU 各国, IN, IR, JP, NG, KP, PH, RU, KR, TR, UA, GB, US}`、`SHOP_SITES = {...}`，每张表头注明来源 URL 与核实日期；`dm_api_available(region) / media_send_allowed(region) / shop_site(region)`；未知地区返回 `None`（渲染「未知，需核实」，**不**默认可用）。
2. 账号：`account_registry.meta.region`（必填，向导选择）+ `meta.shop_region`；`platform_readiness` 新原因码 `region_unsupported`（三态口径同 `REASON_NOT_IMPLEMENTED`），地区不可用的 `official` 模式在向导 / 账号卡渲染为「该地区不支持官方私信 API」+ 替代路径链接。
3. 登记：`platform_registry.py` 若已存在 → 加 `tiktok` 条目（`family=bytedance`, `compliance_visibility=main` 官方 / `restricted` 真机）；否则散表各加一行：`platform_login.SUPPORTED_PLATFORMS` / `DEFAULT_PLATFORM_MODES["tiktok"]={"modes":["official"],"default":"official"}` / `PLATFORM_INSTRUCTIONS(_KEYS)`；`platform_readiness._IMPLEMENTED_MODES` 加 `tiktok:official`；`normalizer.PLATFORM_DISPLAY["tiktok"]="TikTok"`、`_PLATFORM_MSG_ID_FIELDS["tiktok"]=("message_id","msg_id")`；`official_webhook_stats` 三表；`account_identity`；`reactivation_loop`；`unified_inbox_send_routes` 显示名表。

## 5. B —— Business Messaging API：官方 worker + webhook + 令牌 + 向导卡（P0）

**修法**：
1. 新建 `src/integrations/tiktok_webhook.py`（仿 `zalo_webhook.py`）：按官方文档验签；`message_id` 幂等（重放不重复落库）；事件分发——消息接收 → `process_official_inbound(platform="tiktok", account_id=<business_id>, chat_key="tiktok:user:<user_open_id>", …, source={"conversation_id", "message_id", "ad": {...}})`；送达 / 已读事件 → `report_message_status` / `report_read_upto`；图片附件经 `mirror_inbound_media`。挂载进 `admin.py` 那一组；`official_webhook_stats` 计数。
