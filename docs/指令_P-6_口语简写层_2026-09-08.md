## A 三语词典 + 概率 + 会话内一致

- 英文（按档位概率 轻 / 中 / 重）：you→u（30 / 45 / 60%）、your→ur、are→r（仅重档低概率）、I'm→im、don't→dont、going to→gonna、want to→wanna、kind of→kinda、because→cuz、okay→ok、thanks→thx、please→pls、though→tho、right now→rn、to be honest→tbh、I don't know→idk、not gonna lie→ngl、laughing→lol/haha；短句去句末句号；句首小写（中 / 重档）。
- 中文：哈哈哈 / 嗯嗯 / 咋 / 啥 / 木有 / emm / 我靠（重档）；去句末句号；「。」→ 空或「～」按档。
- 日文：w / 笑 / ｗ / 〜；其它语言给最小集（去句末句号 + 常见口语词）。
- 实现：`outbound_humanize.py` 新增 `texting_style(text, lang, level, seed) -> (text, stats)`，在 P-1 起草层净化之后调用；stats 进 `[draft] style_fix=n slang_fix=n`。
