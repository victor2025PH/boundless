## 0. 一句话

球不是没做动效，而是做了别人看不见的动效：待机态按实施59 刻意压到「低于分心阈值」，而球 95% 的时间在待机；形态是「硬壳行星 + 刚性双环 + 图标」，刚体慢转在 46px 上读成图标；真正让 ChatGPT 的球"活"的是它背后的**实时语音回合**，而小智此前是五步文本流程。本批：**待机活化并做减法（P0）**、**面板内会话大球 + 免手动语音回合（P1）**，全部复用既有端点，零后端改动。

## 1. 五视角问题（要点，完整版见会话记录）

- **工程**：待机常驻 4–6 个 blur 旋转层为看不见的动效付费；门禁把「环=4 个」这种实现细节钉成契约；语音链是批处理（录→停→转写→填框→发送→播报五步，无 VAD/自动播报/打断）；实时基础设施（`/api/voice/live` + MiniCPM-o 端到端）不能直接给小智——端到端模型接不了帮助库 grounding；缺 `connecting`/`error` 两态；reduced-motion 把状态信息连装饰一起删了。
- **市场**：球是「自带 AI 员工」的脸，行星图标答的是「帮助按钮」；土星形态不可拥有；演示素材依赖麦克风做不出来；2026 风向（Mico 撤出、OpenAI 把球并回对话、Apple 钉进灵动岛）= 买家要「能干活且诚实」，不要吉祥物。
- **用户**：像按钮不像能对话的东西；分不清活着还是卡住（远程桌面下全静）；语音按五次才听到回答；思考时球在角落 46px；8 小时坐席要「活但安静」；色弱用户靠色相分不清状态。
- **美术**：隐喻冲突（说是能量核画的是行星）；46px 塞 9 层无主次；硬体不显活；好看的光谱只在细环上；匀速旋转是机器语法；轮廓永不变=死；图标与球身争抢。
- **UI/UX**：一个形态干三份工（启动器/状态灯/会话存在感）；8 态解码不了；「待机要静」与「要像 ChatGPT」用幅度解决而非二选一；真正缺口是回合 UX；球无悬停标签、无长按手势；球→面板无连续性。

### 2.2 P1 面板语音视图 + 免手动回合（纯前端，零新端点）

| 项 | 落地 |
|---|---|
| 入口 | 长按球 ≥420ms（麦克风可用时；拖动/单击不变）、`AssistantBall.voice.start()`；浏览器 LAN http 无麦克风则长按等同单击 |
| 语音块 | 取代输入区（语音替代打字）：168px 大球（Canvas 2D，窄屏 132px）+ 状态行（与标题栏短句同文）+ 「打断 / 自动播报开关 / 结束语音」；对话内容仍在消息流里流动 = 实时字幕；44px 波形条退场 |
| 回合状态机 | `connecting` → `listening`（时域 RMS + 自适应底噪 VAD：≥220ms 响动算说话，静默 800ms 判停，单轮 15s 上限）→ 转写（`/api/assistant/transcribe`）→ 识别文本直接成为一问（用户气泡 + `/api/assistant/query` SSE）→ **按句自动播报**（delta 流上句子一完整就送 `/api/voice/tts-test`，入队即预取，首句在余下内容生成中已开口）→ 播完自动回到听；25s 无人声自动结束 |
| 打断 | 点大球 / 「打断」/ 大球聚焦回车：停播报、清队列、掐生成、回到听（显式打断；语音打断 P2） |
| 大球渲染 | 基圆 + 2/3/5 次谐波轮廓调制（振幅随电平：听=麦克风、说=TTS、想=流式 token 到达节奏）+ 内部三团光谱色裁进球体 + 电平辉光 + 听时攻击音涟漪；与角标球同光谱同状态色；lv0 近静态 |
| 演示模式 | `AssistantBall.demo('loop')` 不依赖麦克风，合成电平循环听→想→说；`demo(false)` 收场——录演示/官网/老板验收用 |

### 2.3 P2 语音打断 + 只传说话段 + 首句提前开口 + 时延观测（2026-09-07 凌晨，同批）

原方案 P2 是「流式 ASR + 服务端句级 TTS 推流」。实施中深想后**换了性价比更高的路线**：
转写走 176 GPU、限频 20/分，停顿分段预转写会把 ASR 调用翻倍且分段边界易切词；tts-test
链本身对 edge 快档已无回验 ASR，合成时延主要在 edge 网络往返，服务端推流只省下载
半程且要过压缩中间件的坑。于是把力气花在**不加调用次数就能缩短时延**的三件事上：

| 项 | 落地 |
|---|---|
| PCM 采集 | 会话级 AudioWorklet（Blob URL 装载，与 `voice_call.html` 同款；`addModule` 失败/无 worklet 回落 ScriptProcessor）在音频线程线性插值重采样到 16k、量化 Int16，20ms 一帧回主线程写 40s 环形缓冲；MediaRecorder 退出语音回合（手动 🎤 键仍用它） |
| 只传说话段 | VAD 在 PCM 帧上算（与可视化分析器解耦，安静档照常工作）；开口位置回退 300ms 预卷，判停即切 `[开口−300ms, 现在)` 成 WAV 上传——掐掉开口前最多十几秒的静默：**whisper 对长静默会幻觉出字，且音频时长即转写时延** |
| 语音打断 | 缓冲全程在录；播报/生成期用更高的门（×1.6 + 随播报电平上浮）且要 ≥350ms 连续过门才算人在说话（AEC 后的残余回声短而弱）→ 停播报、掐生成、开口位置带入新一轮（不丢首字）。转写期不看（掐不了且只有零点几秒）。状态行播报期附「说话即可打断」 |
| VAD 迟滞 | 开口候选允许 ≤120ms 的跌门（辅音/两源交错帧）；说完后的 800ms 静默窗只被 ≥120ms 持续响动打断（键盘/关门这类 1-2 帧脉冲不再把「说完了」往后拖）——**假麦克风每 500ms 一声 46-92ms 的 beep 把这两个真实问题都逼了出来** |
| 首句提前开口 | 答案第一段还没到句号、但已到分句（，、：）且 ≥8 字 → 先送这一分句合成；后续按整句（韵律更顺）。首声时延里「LLM 写完首句」与「首句 TTS 时长」两项都随首段长度涨 |
| 限频退避 | 转写 429 → 停 20s 再听（不硬撞）；服务端默认 6/分·120/天 放宽到 20/分·400/天 并可配（`assistant.voice.rate_per_min/rate_per_day`） |
| 时延观测 | `asb_voice_asr_{lt1,1_2,2_4,gt4}`（说完→转写回来）、`asb_voice_ttfs_{lt2,2_4,4_7,gt7}`（说完→第一声）、`asb_voice_barge`；ops 小智卡新增「🎙 语音对话（14 天）」行：会话/回合/打断 手动·语音/两组分桶，首声 ≥7s 占比 ≥20% 亮琥珀 |

## 4. 实施中的深想（相对方案的增量）

1. **像素差不等于生命感**：量化后发现 v2 待机的像素翻动比 v3 还大，却被老板读成静态——刚性旋转被大脑归为"图标在转"。结论写进验收口径：帧差只证非静态，形态由人眼在真实尺寸拍板。
2. **轮廓呼吸不能用 border-radius**：角部形变全落在 mask 渐隐区里肉眼看不到，改为椭圆挤压随慢转换向；悬停微倾改写 CSS 变量进同一条 transform，避免 inline transform 被动画覆盖。
3. **`animation-play-state: paused` 让常驻环零开销**：不删 DOM（门禁与遮挡层序都不用动），待机只是不画。
4. **VAD 在时域 RMS 上做而不是复用可视化电平**：可视化电平只在 lv2 活跃态的 rAF 里更新，安静档/reduced-motion 下不刷新，VAD 会失明。
5. **error 瞬态压过黏性模式态**是正确优先级（真实事件赢），但门禁序列必须等它退场（O9c）。
6. 发现并修掉入场类与输入框类同名导致的面板入场先矮后跳（2026-09-05 引入）。

## 5. 还能再优化（本批刻意未做）

- **转写引擎**：`/api/assistant/transcribe` 走 176 whisper HTTP 往返；进程内已有共享转写器（`get_shared_transcriber`，SenseVoice 亚秒级，synth_verify 在用）。短句优先走它、失败回 176，是首声时延最大的单项——属后端选型决策，未越界。
- 部分字幕（说话时出字）：需要停顿对齐的分段预转写或流式 ASR，会翻倍 ASR 调用；等 `asb_voice_asr_*` 分桶有读数再决定值不值。
- 服务端句级 TTS 推流（chunked mp3 + MediaSource）：省的是下载半程，且要过压缩中间件；等 `asb_voice_ttfs_*` 说明首声瓶颈在哪再做。
- 大球可选 WebGL 档（noise 位移 + Fresnel），角标球永不上 WebGL。
- 球飞入面板标题栏的 FLIP 过渡（现在面板开着时角落球仍在，只是不抢）。
- 46→52px 尺寸与三档待机幅度需老板真机拍板（`?orbidle=calm|breathe|flow` 并排看）。
- 远程桌面场景核实：在坐席机 DevTools 跑 `matchMedia('(prefers-reduced-motion: reduce)').matches`，偏好页诊断行现在会直接写明原因。
- 语音打断门限（×1.6 + ≥350ms）按办公室耳机/内置麦估的，真机有回声误触或漏触时调 `VOICE_BARGE_MS` / `thB` 两处。
