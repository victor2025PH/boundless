## 台账字段：v1.1 口径（二批 `067a0b62` 起）

- hold 行（`kind=hold`；旧行缺 `kind` 按 hold 读）：v1 全部字段 + `lang` / `intent` / `emotion` / `persona_id` / `peer_text_fp`。
- outcome 行（`kind=outcome`，按 `draft_id` 关联 hold）：`outcome` ∈ `sent`（sent_at>0 真送达）/ `cancelled`（reason=decided_by：send_blocked / mode_downgraded / channel_mutex / pilot_native / superseded_by_inbound / work_schedule_regen / stale_peer）/ `rejected`（人工拒）/ `approved_unsent`（approved 超 30min 无 sent_at＝投递失败宁丢不重发 / 延迟窗内客户插话放弃）/ `missing`（草稿行被 cleanup 清理或 7 天仍未终局）；`latency_sec`＝放行→终局。
