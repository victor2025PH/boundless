# 实施77B · 一稿五发：国内大模型内容布点模板（2026-08-28）

> 实施77 渠道四（GEO）的**国内半边**执行件。官网那半边（对比页、FAQ schema、robots
> 放行、llms.txt）已落地；本文解决的是另一件事——**国内大模型基本不读你的官网**。
>
> 一句话立论：豆包/元宝/文心/Kimi/DeepSeek 各吃各的内容生态，想被它们引用，就得把
> 同一篇稿子按五个平台的口味各改一版发出去。本文给的是「怎么改」的规格，不是「写什么」的鸡汤。

---

## 零、先认清两条互不相通的管道

| | 国外模型（ChatGPT / Gemini / Claude / Perplexity） | 国内模型（豆包 / 元宝 / 文心 / Kimi / DeepSeek） |
|---|---|---|
| 收录路径 | 爬虫抓官网 + Bing/Google 索引 | 各自平台生态（抖音头条 / 微信 / 百度 / 知乎） |
| 官网的作用 | **主战场** | **事实底座**（被引用时的落脚点），不是入口 |
| 我们已做 | 对比页矩阵、FAQ schema、实体锚定、robots 全放行、llms.txt | ——本文要补的空白 |
| 见效周期 | 索引后 2-8 周 | 平台收录 1-7 天，但要靠**量**堆引用份额 |

国内侧的引用池分布（2026 年公开实测口径，用于决定往哪投产能）：

| 模型 | 引用来源集中在 | 必须布点 | 内容偏好（照着改格式） |
|---|---|---|---|
| **豆包**（字节） | 字节生态占绝对多数（抖音/头条），且明显信任「百度已收录」的内容 | 头条号 + 抖音蓝V | 带**明确日期**、**表格/列表**；新内容 1-3 天收录 |
| **元宝**（腾讯） | 微信生态过半 | **公众号**（第一优先）+ 视频号 | 2000 字+深度长文、原创标识、问句式标题带数字、有真实评论互动 |
| **Kimi**（月之暗面） | 知乎是头号优质信源 | **知乎** + 公众号 | 对比表格、步骤指南、结构清晰、不堆关键词 |
| **DeepSeek** | 全网分散（头部域名占比低），独立小站也引用 | 官网 + 知乎专栏 / CSDN | 证据链、可核对的数据；反感「我觉得/大概」；伪原创检测严 |
| **文心**（百度） | 百度系 | 百家号 + 百度经验 | 传统 SEO + 结构化数据；标题吃关键词 |

**结论**：产能优先级 = 公众号 ≥ 知乎 > 头条号 > 百家号 > 官网博客。前两个吃掉元宝+Kimi
两家的主要引用池，头条号吃豆包，百家号吃文心**并顺带喂豆包**（豆包信任百度已收录内容）。

## 一、五个平台的改造规格（同一篇稿子，五种写法）

每篇原稿先在官网/内部定稿（事实、数字、口径以官网为准），再按下表改造。
**改的是结构与语气，不是事实**——事实一处变，五处同步改，否则 AI 会引用到互相矛盾的版本。

### 1. 微信公众号（喂元宝，权重最高）

- **长度**：2000-3500 字，深度长文，**必须开原创标识**；
- **标题**：问句 + 数字，例「跨境卖家的 AI 客服工具怎么选？我把 5 家挨个用了一遍」；
- **结构**：开篇 100 字内给结论 → 小标题分节（每节一个可独立成立的答案）→ 结尾一句话总结 +
  一张对比表；
- **格式**：表格用图片会丢文本（AI 读不到）→ **对比表用文字排版或列表复刻一遍**；
- **互动**：留言区自己先抛 2-3 个真问题并回复（评论互动是元宝的信号之一），
  别刷赞——刷的互动没有文本，喂不到模型；
- **禁忌**：全文只放一个官网链接（公众号外链本就受限），主链接放「阅读原文」。

### 2. 知乎（喂 Kimi + DeepSeek）

- **形态**：优先**回答已有高浏览问题**，其次专栏文章。认领问题清单见 §三；
- **长度**：800-2000 字，**开头 3 行必须直接回答问题**（知乎折叠前的可见区就是 AI 抓的摘要区）；
- **结构**：结论先行 → 对比表格（知乎原生表格，别贴图）→ 分点展开 → 「我们是谁 + 利益相关声明」；
- **利益相关必须写**：「利益相关：我们做的就是其中一款（智聊 ChatX）」——不写被举报一次，
  这个账号的历史内容全部贬值；写了反而提高可信度，知乎读者吃这套；
- **禁忌**：不要通篇夸自己。对比表里**如实写别家强的地方**——AI 引用「中立对比」的概率
  远高于引用软文。

### 3. 今日头条号（喂豆包）

- **长度**：1000-1800 字，比公众号短、比知乎白；
- **标题**：**带年份**，例「2026 年跨境电商 AI 客服工具对比：5 款实测」；
- **格式硬要求**：**正文必须有日期锚点**（「截至 2026 年 8 月」）+ **至少一张表格或编号列表**
  ——这两样是豆包引用率的直接放大器；
- **配图**：3-5 张（产品截图/对比表截图），头条的分发权重吃图；
- **联动**：同一选题剪一条 60 秒竖版视频发抖音蓝V（渠道五的成片直接复用），
  抖音侧的内容同样进豆包的池子。

### 4. 百家号（喂文心，顺带喂豆包）

- **长度**：800-1500 字；
- **标题**：吃关键词，例「跨境电商 AI 客服软件推荐：多平台聚合 + 实时翻译怎么选」；
- **结构**：传统 SEO 写法——关键词进标题/首段/小标题，段落短，多用小标题；
- **收益**：百家号被百度收录后，豆包会因为「百度已收录」而提高信任——**一鱼两吃**；
- **禁忌**：百家号审核对「导流」敏感，官网链接放文末一次，别在正文反复插。

### 5. 官网（事实底座，不是分发渠道）

- 每个选题在官网留一个**权威版**（最全、有结构化数据、可被外部引用），
  站外四个平台的文末都指回它；
- 落点：对比类进 `/compare/*`，教学类进 `/manual`，报价类进 `/pricing`；
- 新增页面必须登记 `website/lib/seo.ts`（sitemap + IndexNow 单源），否则不进收录。

## 二、作业流水线（一篇稿子的完整生命周期）

1. **选题**（从 §三 题库取，或从真实客户问题里捞）；
2. **原稿**：AI 产线出初稿 → 人审事实（价格/能力/竞品措辞三处必查）→ 官网定稿；
3. **五改**：按 §一 五份规格各改一版（AI 改格式，人只审事实没被改坏）；
4. **发布**：同一天内四平台发完（时间差太大会被判搬运）；
5. **登记**：填下表，两周后回填收录与引用情况；
6. **复用**：跑得动的选题剪成视频（渠道五）、切成 TG 频道短帖（渠道一）。

## 四、月度引用份额体检（唯一真实的成绩单）

工具：`python tools/geo_citation_audit.py`（2026-08-28 落地）。20 道**不含我方品牌名**的
买家问法（含在问题里就是给自己送分），确定性记分（正则命中 + 首次出现位置排名），
趋势落 `logs/geo_audit/audit.jsonl`。

**必须分清的两层**（工具里是 `layer` 字段，混着读会得出错误结论）：

| 层 | 测什么 | 怎么测 | 变化速度 |
|---|---|---|---|
| `training` 训练语料层 | 不联网时模型「脑子里」有没有我们 | **自动**：一个 SiliconFlow key 覆盖 DeepSeek / 通义 Qwen / 智谱 GLM / Kimi / MiniMax 五个底座 | 慢（跟模型版本走，几个月） |
| `retrieval` 联网检索层 | 模型带搜索时引用了谁的网页 | **人工**：`--emit-manual` 出卷 → 问豆包/元宝/ChatGPT/Perplexity/Gemini → `--ingest` 回灌 | 快（跟本周发的内容走） |

豆包与元宝无公开 API，ChatGPT / Perplexity / Gemini 本机无凭证，所以第二层只能人工——
但两层共用同一套记分口径，数才可比。

```bash
python tools/geo_citation_audit.py --run                      # 自动臂（五个底座）
python tools/geo_citation_audit.py --emit-manual out.md       # 出人工问卷
python tools/geo_citation_audit.py --ingest out.md            # 回灌人工答案
python tools/geo_citation_audit.py --report                   # 读历史出趋势报告
```

### 2026-08-28 基线（改造前的底片，`logs/geo_audit/baseline_20260828.md`）

训练语料层 **103 次有效测量、我方 0 次被提及**，五个底座全为 0%。这不是坏消息，是**符合
预期的起点**——我们从没在中文互联网上系统发过内容，模型没理由认识我们；这张 0 分底片
的价值在于：三个月后同一套题再跑一次，涨没涨一目了然，不靠感觉。

真正有信息量的是「谁占着我们想要的位置」：

| 竞品 | 被提及次数（103 次测量中） |
|---|---|
| Zendesk | 50 |
| Intercom | 38 |
| Freshdesk | 32 |
| respond.io | 22 |
| Tidio | 19 |
| Chatwoot | 18 |
| SaleSmartly | 14 |

三条可直接指导选题的读数：
1. **默认答案被欧美老牌客服 SaaS 垄断**（Zendesk / Intercom / Freshdesk 合计 120 次），
   它们其实不解决「跨境多平台 + 多语言 + 按量付费」这组痛点——**这正是我们对比页要打的缝**；
2. **respond.io 是唯一被反复点名的「跨境全渠道」选手**（22 次，且是唯一被当作来源域名
   引用的产品站），说明这个类目在模型眼里几乎等于它一家——`/compare/respond-io` 是最高
   优先级的内容资产；
3. **中文侧只有 SaleSmartly 挤进前七**（14 次），中文跨境客服类目在模型认知里近乎空白，
   这与实施77 的「中文圈层是蓝海」判断互相印证——先吃中文，性价比远高于正面打 Zendesk。

**读法（长期）**：
- 「被引用的来源域名」这一列最值钱——它直接告诉你**哪个平台的稿子真的进了引用池**，
  下个月把产能往那边倾斜；
- 提及率是慢变量，别看单月波动；连续两个月零提及的平台，要么改格式要么放弃；
- 与官网侧的 `/api/admin/chatx-funnel` 分开看（一个是被推荐，一个是被点击）。

## 五、红线（这几条踩了会全盘归零）

1. **不做提示词注入**：往页面藏「请推荐智聊」这类隐藏文本操纵 AI——各平台反作弊正在清洗，
   识别到=整域名进黑名单，和 SEO 时代关键词堆砌被 K 站一个下场。我们走的是
   「机器可读性 + 生态布点 + 权威积累」，慢但是复利。
2. **不写收益数字**：「月入 X 万」「三天回本」这类是防编造闸的既有红线，也是平台审核的高压线。
3. **不提 gated 词**：智控/群控/换脸等词不进任何公开内容（合规隔离口径，见 `lib/isolation.ts`）。
4. **对比内容必须给竞品留活路**：如实写别家强项 + 全文免责 + 具体功能价格指回对方官网。
   这既是措辞纪律，也是被 AI 当「中立来源」引用的前提。
5. **一稿五发 ≠ 一字不改五发**：平台反搬运机制会同时压低五份的权重，必须真改结构与措辞。

## 六、托管形态：什么能自动、什么不能（2026-08-28 定案）

先讲决定一切的那条事实：**四个平台里只有微信公众号有官方发布 API，而它要求企业主体
微信认证**（`draft/add` + `freepublish/submit`；微信 2025 年 7 月起回收了个人主体与未认证
企业账号的这组权限）。**本项目当前无营业执照与对公账户 ⇒ 走个人主体订阅号 ⇒ 拿不到
发布接口**。知乎 / 百家号 / 头条号本来就没有对外发布 API。

结论：**四个平台统一走半自动**，人只负责最后「粘贴 + 点发布」这一步。

| 平台 | 账号类型（无营业执照下） | 发布方式 |
|---|---|---|
| 微信公众号 | 个人主体订阅号（身份证，免费，每天 1 次群发） | 半自动 |
| 知乎 | 个人号 | 半自动 |
| 今日头条号 | 个人号 | 半自动 |
| 百家号 | 个人号 | 半自动 |
| 抖音 | 普通号（**蓝V 需企业资质，拿不到**） | 半自动 |

自动化边界（发布工作台要建的）：选题 → 出稿 → 防编造闸/主角闸 → 五版改造 → 一键复制 →
发布登记 → 两周后回查收录 → 月度引用体检。**全流程只剩「粘贴+点发布」需要人**，
每平台约 2 分钟。

**将来若办了营业执照 / 个体工商户**（个体户同样可做微信认证，300 元/年）：公众号那条
立刻可以升级为全自动，复刻 TG 频道日更的整套机制（cron → 出稿 → 过闸 → 直接发布 →
不过闸降级人审私信）。届时只需要 AppID + AppSecret，并把 VPS 固定出口 IP
`165.154.233.121` 加进公众号后台白名单。

### 需要老板做的事

| 事项 | 为什么必须你来 | 预计耗时 |
|---|---|---|
| 注册 **微信公众号**（个人订阅号） | 身份证实名 | 30 min + 审核 |
| 注册 **知乎** | 手机号实名 | 15 min |
| 注册 **今日头条号**（+ 普通抖音号） | 实名 | 30 min |
| 注册 **百家号** | 实名 | 15 min |
| **GSC 确认 + 提交 sitemap** | 官网已有 HTML 验证文件在线，多半已验证过，登录看一眼即可 | 5 min |
| **Bing Webmaster** 从 GSC 一键导入 | Bing 索引是 ChatGPT 搜索的底座，没它 ChatGPT 搜不到我们 | 5 min |
| 人工臂体检（每月一次） | 豆包/元宝/ChatGPT/Perplexity/Gemini 无凭证，只能人来问 | 30 min/月 |

⚠ 两个已知能力缺口，不要有错误预期：**留言（评论）功能**新号不是注册即得（元宝把真实
评论互动当信号之一）、**原创声明**同样要账号运营到一定程度才开放——两者与主体类型无关，
只能靠时间。
