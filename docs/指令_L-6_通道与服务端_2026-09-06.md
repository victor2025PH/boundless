## 3. B —— 桌面包剥离内网默认（P0）

**根因落点**：`gpu_watermark.py` L20 默认 `192.168.0.140:11434`；`voice_transcriber.py` L415 / `avatar_voice.py` L1449 默认 STT `192.168.0.140:7854`；`spoken_style_bridge.py` L270 默认 `192.168.0.173`；`health_watchdog` LAN GPU 探针；`outbound_gate.py` 注释里的 `192.168.0.198`。这些在 `desktop_mode`（客户机）下不可能可达。

**修法**：
1. 引入单一判定 `is_desktop_client()`（已有 `app.desktop_mode` 就复用）：为 True 时上述模块**不注册 LAN 端点、不探测**，只走 `hosted_gateway`（识图 / STT / Embedding / 改写都经官网网关）；配置里显式写了 LAN 地址的（内部坐席机）不受影响。
2. `health_watchdog` LAN GPU 探针与「本地冗余归零」告警在 desktop_mode 下关闭；Embedding 熔断器在无本地端点时不进入「熔断」而是「未配置」态（下游学习队列相似度显「未计算」，接 L-4 F）。
3. 转录器：`OpenAI/AvatarWhisper 双级返空` 的兜底链在 desktop_mode 下只走网关 ASR，失败明确告知「转录服务暂不可用」而非返空。
4. 落点表列出剥离后**哪些功能在客户机上会变成「未配置」**（如 spoken_style 改写、gpu_watermark），交老板知悉。

**验收**：skuio 机装 1.0.75 后 3h 无「LAN GPU 不可达」toast、无 Embedding 熔断；`tests/test_desktop_no_lan_defaults.py`：desktop_mode 下配置解析不含 `192.168.` 地址。

## 4. C —— 贴纸按类型落盘（#195，P2）

**根因落点**：`protocol_bridge.tg_media_meta` L361 对所有 `message.sticker` 返回 `("sticker", ".webp")`；动图贴纸（`sticker.is_animated` → .tgs Lottie）和视频贴纸（`sticker.is_video` → .webm）被存成 .webp，前端 `<img class="msg-media-sticker">` 渲染不了 → 破图；识图拿到非图片字节也失败。

**修法**：`tg_media_meta` 按 `is_animated → ".tgs"`、`is_video → ".webm"`、其余 `.webp`；`download_tg_media` 对 `.tgs` 额外下载 `sticker.thumbs[0]`（.webp/.jpg）作静态缩略图并存 `media_ref_thumb`；前端 L9672 分支：`.webm` 用 `<video autoplay loop muted playsinline>`，`.tgs` 显示缩略图 + 「动图贴纸」角标（不引 lottie 库），`.webp` 原样；识图对 sticker 跳过或用缩略图。钧的诊断包不记落盘文件名——**修完请值守让钧再收一次动图贴纸核实**（他 04:05 还没答「会不会动」）。

**验收**：`tests/test_tg_sticker_media_meta_195.py`：三种 sticker 扩展名正确；前端渲染分支三态。

## 5. D —— 首启随机 secret_key（P1）

**现象**：两机每次 boot：`[SECURITY] 检测到默认 secret_key 且绑定非本地地址 0.0.0.0；为防不安全暴露，Web 后台改绑 127.0.0.1`（`web_app.py` L1001）；用户管理页密钥占位（QEDG4X）。副作用：改绑 127.0.0.1 后**局域网 / 手机扫码配对入口不可用**（#57 Bao「局域网入口未就绪」同族）。

**修法**：桌面首启若 `web_admin.secret_key` 为默认值 → 生成随机 32 字节写入 `config.local.yaml`（用户不可见，同 `auth_token` 处理方式）→ 不再触发改绑；`[SECURITY]` 路径保留给真正手写默认值的服务器部署。用户管理页「密钥」行显「已自动生成」而非占位。

**验收**：干净数据目录首启两次 → 无 `[SECURITY]` 行；`/kz` 配对地址可达（本机 LAN IP）。
