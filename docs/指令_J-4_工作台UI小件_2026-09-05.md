### 证据 / 现状（已核）

- 前端：`unified_inbox.html` L2484 `_acUnreadBadge(unread,attn,plat,aid)` 渲染角标，L2520 拼 `/account-unread` 查询；mark-read 调用点 L7789 / L10609；`archivedUnreadByAccount` L2126 / L6214（#142 被埋会话界面化）。

### 修
1. 六处 `_acUnreadBadge` 渲染点统一：**数字本身**可点 → 打开 `/account-unread` 明细浮层（列表 + 「全部标已读」→ `mark-account-read`），`stopPropagation` 不触发切账号。

3. 被埋会话告警上屏：L5055 那行「归档中还有 N 条未读 · 查看」入口在 archivedUnreadByAccount>0 时**默认可见**（现在似乎只在筛选条某态下）；给「一键取消归档这 N 条」按钮（已有 mark-account-read，取消归档若无端点则只做「查看+标已读」，落点写报告）。
4. 归档会话有新入站自动浮回默认视图——**先核** `conversations.archived` 在新入站时是否被清；不是前端能改的就写进报告（后端归 store/ingest，不属本批）。
