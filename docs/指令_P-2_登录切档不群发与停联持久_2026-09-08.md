## A 回填标记：同步回来的历史不进自动化

- 修法：边车对 `messaging-history.set` / `chats.upsert` 提取的消息、`app-state resync` 后补的消息，payload 加 `backfill: true`（含 `source: history_set|chats_upsert|resync`）；后端 normalizer 落库带 `meta.backfill=1`，**不**发「新入站」事件给起草 / 关怀 / 目标 / 问候 / 引用 / 未读角标（角标按产品既有口径：历史不算未读）；日志一行 `[inbound] backfill=1 conv=… ts=… skipped_automation=1`。Telegram `backfill_telegram` / `deep_backfill_tg_history`（`protocol_bridge.py` L1189 / L1450）同口径核对。
- 验收：重装 + 登录 → 收件箱有历史、零 `auto_generate_draft`；tests：normalizer 收到 backfill 行不触发回调。
