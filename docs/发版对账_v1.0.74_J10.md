## 交 J-4（草稿旁记忆 chips · 后端已备好，前端落点在 `unified_inbox.html`，本单不碰）
- **接口**：`GET /api/episodic-memory/used?conversation_id=<platform:acct:chat>&limit=1`（`limit`＝最近几轮；也可 `memory_key=`）。
- **返回体**：`{ok, count, batches: [{batch_id, ts(epoch 秒), chain: "inbox"|"direct", inbound_msg_id, conversation_id, items: [{id, content, source: user_stated|ai_inferred, tier: raw|stable|stale, review_reason, impact: high|normal, source_quote, source_ts, status, recall_count, last_recalled_ts, memory_key, …} | {id, deleted: true}]}]}`——最新批在前，`items` 顺序＝当轮 prompt 里的 bullet 顺序；`count == 0` ＝这轮没用记忆（不要渲染空 chips 条）。
- **动作**：「一键不再使用」→ `POST /api/episodic-memory/{id}/ignore`（软删，可在维护区恢复 `POST {id}/restore`）；「确认属实」→ `POST {id}/confirm`；冲突 → `POST /api/episodic-memory/resolve-conflict {keep_id}`。
- **建议渲染位置**：草稿卡底部（发送按钮上方）一行 chips「本轮用了 N 条记忆 ▾」，展开列 `content`（`impact=high` 红点、`source=ai_inferred` 琥珀点、`review_reason` 非空加「需要你看」小标），每条右侧「不再使用」；取数时机＝草稿生成完成后（`record_recall` 在生成前注入点写入，草稿到手时批次已在）。取 `batches[0]`，`inbound_msg_id` 可与草稿所回复的入站消息 id 对账（同一轮）。
- **自证**：AI 记忆页 → 打开任一客户档案抽屉 → 顶部「最近被用」分区（同一接口按 `memory_key`）。
