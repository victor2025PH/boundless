## 2. A —— 语音三态 + 保存校验（#205，P1）

**现象**：语音 tab「语音 BACKEND」五选一（继承全局 / Edge TTS / OpenAI TTS / 声音克隆(命令) / 克隆音色·avatar_clone）+ 手填 VOICE ID；Mizuki `avatar_clone + ja-JP-NanamiNeural` 保存成功且页面标「已绑定克隆音色: ja-JP-NanamiNeural」；日志 04:44/04:48 `backend=avatar_clone voice=ja-JP-NanamiNeural CER=0.719 重合成 #93 应克隆未克隆`。

**修法**：
1. `personas.html` 语音 tab 改三态单选：**「用我上传的录音（克隆声）」/「用预置声」/「不发语音」**。引擎由系统决定（克隆 → avatar_clone；预置 → 全局配置的 TTS），不再让用户选 backend；「声音克隆(命令)」移入开发者模式（D-L2）。
2. 预置声选择器：按语言 · 性别 · 风格筛选 + 试听（复用现有 `voice/tts-test`），不再手填 VOICE ID。
3. 保存校验（前后端同做，`persona_routes` 保存端点）：克隆态必须有 `reference_audio_path` 且文件存在；预置态 voice 必须在该引擎的合法音色表；`avatar_clone + 预置音色名` 直接拒绝并给人话原因。存量非法组合（Mizuki）保存时提示修正，不静默改。
4. 新建人设默认「不发语音」（D-L4）；绑定文案按实际类型显示（「已绑定克隆声：<录音文件名>」/「预置声：日语 · 女 · Nanami」）。

**验收**：`tests/test_persona_voice_tristate.py`：三态互斥 / 非法组合 400 / 新建默认 off；Mizuki 打开编辑器看到「配置需修正」提示。

## 3. B —— 兜底不换声（#205 后半，P1）

**现象**：steven 试听三次：无反应 → 系统默认女声 → 正确克隆声（V85TY9）；ERS5QQ 指出运行时兜底 `avatar_clone 失败 → edge_tts 默认声` 让男人设变女声。

**根因落点**：`src/ai/tts_pipeline.py` L868 / L1664「主后端失败 → 回落到免基建的在线 edge_tts」+ L717 `safe_edge_voice(voice, fallback=_EDGE_VOICE_DEFAULT)`——默认 edge voice 不看人设性别/语言。

**修法**：克隆态人设合成失败 → **不回落任何预置声**：自动链改发文字并在账号旁/草稿卡标「语音引擎离线，本条已改发文字」；试听走同一判定，界面提示「引擎离线」而不是放别的声音。预置态才允许回落，且回落音色必须同语言同性别（`safe_edge_voice` 接 persona gender/lang 参数，找不到同类就改发文字）。落 `[tts-fallback]` INFO 记原因。

**验收**：`tests/test_tts_no_cross_gender_fallback.py`：断开 avatar_clone → 输出为 text 降级 + 提示，不出 edge 音频；预置态回落音色性别一致。

## 4. C —— JSON 导入回滚 + 加闸（#203，P1）

**现象**：1.0.74 基础 tab 顶部**默认展开**「从 JSON 导入字段…／粘贴 PROFILE JSON」+「解析并填充」；高级字段 JSON（voice_profile / capabilities.photos）直出。误粘 + 误点 + 保存 = 服务中人设被整体替换（WYGNJ2）。

**修法**：
1. 先回滚：JSON 导入块恢复折叠、**client flavor 默认隐藏**（读 `ui_visibility.flavor`，同 `nav_schema.CLIENT_HIDDEN_ITEM_IDS` 机制；开发者模式可见）。
2. 保留时的闸：「解析并填充」→ 先弹逐字段对照预览（旧值 → 新值，可勾选）→ 二次确认 → 填充后 30s 可撤销（`_profile_history` 已有快照栈，复用）→ 目标人设有绑定/活跃会话时红字警示 → JSON 不合法或含未知字段直接拒绝。
3. 高级字段 JSON：`voice_profile` 由 A 的语音 tab 表单接管；`capabilities.photos` 改基础 tab「可发照片」开关；其余未知字段后台静默保留不展示（保存时原样回传）。

**验收**：`tests/test_persona_json_import_guard.py`：client flavor 不渲染导入块；填充必经预览 + 确认；撤销恢复旧值。
