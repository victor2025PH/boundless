## 三、验收口径（交 P-5 回访 skuio；只给版本号不给日期）

1. **后台监听**：1.0.79 clean 装 → `netstat -ano | findstr 18799` 只见 `127.0.0.1:18799`（不再有 `0.0.0.0`）；启动日志不再有「Web 监听 0.0.0.0」WARNING。
2. **开关位置**：系统设置 → 「连接与安全」卡（`/settings#lan` 直达）→「允许局域网设备连接（手机扫码操控需要）」默认关。打开 → 若 Windows 网络类别为「公用网络」弹二次确认 → 保存后提示「重启后端后生效」+「立即重启应用」按钮 → 重启后 `netstat` 见 `0.0.0.0:18799`，壳右上角常驻小横幅「后台对局域网开放 · 192.168.x.x:18799 · 手机扫码」。关闭开关 + 重启 → 横幅消失、回 127.0.0.1。
3. **扫码页引导**：开关关着时点小智「手机操控」→ 红字「局域网访问未开启…」+「去设置开启」按钮直达开关（不再是「升级到最新版自动放开」）。
