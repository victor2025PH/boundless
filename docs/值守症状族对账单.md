# 值守症状族对账单（首版 2026-09-02，值守循环 v3 §H 的落地台账）

> 用途：同一**用户可见症状**背后往往有多个独立根因，按工单号记账会导致「修一个根因就说已修复→用户撞上下一个根因→信任-1」。
> 本表按症状聚合全部已知根因，回访与群公告一律引用本表口径（「修到第 N 层，还剩 X」）。
> 更新纪律：每次新定性、每次发版对账、每次回访复验后随手更新；「敞口」列为空才允许对该症状说「已修复」。

## 使用备注

- 新增症状族的门槛：同一症状出现**第二个独立根因**时立族，不等第三个。
- 「状态」列只允许：已修（vX）/ 未修（指令已交/未交）/ 等证据（缺什么写什么）。
- 回访引用本表时对用户只说层数和症状语言；工单号是内部索引。
