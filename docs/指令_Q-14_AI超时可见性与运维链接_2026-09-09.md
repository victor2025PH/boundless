## A 客户端超时与重试对齐（D-Q10）

- `ai.timeout` 默认 30 → **60**（≥ 网关 chat 预算 55s + 余量；`connect=5` 不变），`ai_client.py` 默认值与 `config.desktop.min.yaml` 同改；存量显式写过 30 的不动（基线只补缺席键——与 Q-4 红线一致，写落点表说明）。
- 重试：连接类错误（connect / reset / 网关 502·503）重试 1 次；**读超时不重试**（上游可能仍在生成，重试 = 双倍成本 + 双倍延迟；超时走 None）。
- prompt 预算：系统提示 + 域包 + 目标注入 + few-shot + 历史 合计 token 上限（默认 6k，可配），超了按顺序裁：历史 → few-shot → 注入长度；日志 `[ai] prompt_tokens=… trimmed=…`。
- 验收：tests 三例（60s 读超时 / 连接错误重试 1 次 / 读超时不重试）；回放 09-08 23h 的长 prompt 用例不再 30s 断。
