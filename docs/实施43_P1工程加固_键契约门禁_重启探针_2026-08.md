## P1-3 重启装载探针（`tools/post_restart_probe.py` + `restart_instance -Probe`)

**背景**：`.py` 搭重启窗装载，「装没装好」本周期靠手写了三轮一次性探针。

**核心招法**：用 `/openapi.json` 路径表验「路由真装载」——flag 关的端点运行时
404 与「路由没注册」的 404 无法区分；openapi 登记的是注册事实，零歧义
（welcome/agent-tasks 等 flag 门控端点注册无条件、门在 handler 内）。

**组成**：openapi 期望路径表（新批次往 `EXPECTED_PATHS` 追加）+ 8 项活体应答
（合规端点/部署档/boss-value/周报 value/备货聚合/静态件…）；exit 0/1/2；
`restart_instance.ps1 -Probe` 挂在 DONE 之后**报告性质**（探针红=黄字提醒，
绝不改变重启结果——重启已成功，红行的含义是「重启前代码就不在盘上/注册炸了」）。

**首跑实弹（15:40，zhiliao）**：8 PASS + **1 FAIL 如实点名两条未装载路由**
（`/api/agent-tasks`、`/api/personas/{pid}/speech-print`——均在最近一次重启
之后落盘，正搭下窗车）。工具首跑就演示了自身价值：它报的不是故障，是真相。
