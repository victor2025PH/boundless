## 关键判定语义（都有门禁钉住）

- **完成度分母只算适用项**（防「永远到不了 100%」的假焦虑）：人设显式
  `capabilities.photos: false` → 相册行不适用；spoken_style 包未随部署 → 指纹行
  不适用。其余四项全✓＝该形态下的满分。
- **音色行**：克隆后端（avatar_clone/minicpm_clone）必须参考音落盘才算备；
  逐字稿 sidecar 单独点名（缺=强情绪通道被强制中性，Phase12 既定语义）；
  非克隆后端配了人设级音色＝「基础语音」就绪（如实分档不硬贬）。
  ⚠ 取值坑：`resolve_voice_cfg` 的 `reference_audio` 在返回值 `voice_profile`
  层（顶层只提升 backend 等四键）——首版读顶层导致三红，已修并有门禁。
- **台词行**：只认人设专属 `<pid>.txt`；`_common.txt` 是共享基线单独计数，
  **不得顶替**专属行（门禁 `test_common_lines_do_not_satisfy_persona_row`）。
- **指纹行**：键=`resolve_spoken_name(persona)` 逐字一致（含全角括号，与
  spoken_style_bridge 运行时同口径）。

## 实施中的两次深想改向

1. **刻意不做规格原文的「自动补 speech_prints 占位」**：占位条目会**消音**
   「缺指纹」这个有用信号（空 guide 占位＝人设只剩通用口语层，跟没有一样），
   且自动写 git 跟踪文件会持续弄脏共享树。改为：面板红行点名 + 一键复制正确
   schema 的模板片段——规格的意图（新人设不静默缺指纹）由更诚实的机制承担。
   **2026-08-18 升级（实施42）**：「复制模板贴文件」对打包态客户走不通（出厂件
   在只读安装目录）→ 面板模板改可编辑 + 「保存到本实例」直写数据区 overlay，
   包内消费经运行时重定向吃合并视图；本条的点名语义不变，出口从人肉贴文件
   升级为一键自助。
2. **中间态特性探测**：模板热更新**立即上生产**而端点 `.py` 要等重启窗——
   点新 tab 会 404。加 404 → 「随下次重启生效」友好态（WP-4 会员卡同款
   feat-probe 模式），每一步保存自洽。
