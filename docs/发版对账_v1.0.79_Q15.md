## 〇 为什么一句 sexy 就哑火（Z25RQS / 9JP5SZ）

1. **一刀切**：`chat_assistant_service._RISK_TERMS["adult"]` 命中一个词（nudes / sex / 裸照…）→ `risk=high` → `autosend_policy.decide` shadow×auto_ai×high → L1 `risk_high_review` + `review_required` → drafts.py `tag_needs_human(reason=high_risk)`。开黄腔一句「you look sexy haha」和「send nudes now」走的是同一条路。
2. **拦后沉默**：转人工只有标签 + 一条 L1 待审稿，客户端什么都收不到；Q-3 之后 `needs_human` 成闸，后续自动稿也一并不发——会话从「AI 在聊」瞬间变成「没人理」。
3. **卡片看不出类别**：`handoff_meta.reason=high_risk` → 原因条只写「命中高风险拦截」，坐席要翻草稿 `risk_reasons` 才知道是成人内容还是支付词。
